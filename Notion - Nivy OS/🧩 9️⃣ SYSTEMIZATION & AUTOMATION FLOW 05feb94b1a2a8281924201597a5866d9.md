### 🔹 AUTOMATION FLOW FRAMEWORK

**Step 1 — Map all recurring processes**

- Identify repetitive actions across departments.
- List them in a “Process Inventory Sheet” (e.g., lead intake, client reporting, payroll).

**Step 2 — Standardize each process**

- Create a **Process SOP** for every recurring workflow.
- Include responsible person, tools used, steps, and time duration.

**Step 3 — Automate**

- Use **tools like Zapier, Make (Integromat), n8n**, or native integrations.
- Connect data flows between CRM → Project Tool → Finance → Reports.

**Step 4 — Centralize**

- Store all processes and automations inside a **Notion / Outline “Agency OS” workspace**.
- Link every automation to its corresponding SOP.

**Step 5 — Monitor**

- Use dashboards to monitor automation health and process KPIs.
- Review monthly under Governance Loop.

### 🔹 EXAMPLE: CLIENT ONBOARDING AUTOMATION FLOW

```
Lead Captured in CRM
   ↓
Client Contract Sent (via automation)
   ↓
Payment Link Shared + Auto Invoice Generated
   ↓
Welcome Email + Access Form Sent
   ↓
Project Auto-Created in PM Tool (ClickUp/Asana)
   ↓
Team Assigned + Kickoff Meeting Scheduled
   ↓
Status Updates Auto-Synced to Dashboard

```

✅ Result: Onboarding time reduced from 3 days → 3 hours
