### **2️⃣ Master Index**

- Central database / table for all topics
- Columns / Fields:
    - Index ID (`STR-01`, `MKT-01`, `OPS-01`)
    - Department
    - Topic
    - Subtopic / SOP name
    - Type (SOP / Playbook / Script / Decision)
    - Version (v1, v2…)
    - Notion Page Link
    - Tags / Keywords (#hashtags)
    - Status (#Draft / #Approved / #Deprecated)
    - Reference Chat (ChatGPT session ID, archive folder link)
    - Last Updated

---

### **3️⃣ Page Title Standardization**

- Fixed format for all pages:

```
[Emoji] DeptCode-TopicCode-ShortTopicName | Department | Type | vX

```

- Example: `📈 MKT-01-Growth Engine | Marketing | Playbook | v2`
- Purpose: New joiners understand **department, topic, type, version at a glance**
