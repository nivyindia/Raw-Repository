## How to Use This Library

1. Find the template by **Use Case** in the table below
2. Open the linked template page, **duplicate it** for your use
3. Fill in the `[BRAND]`, `[DATE]`, and `[OWNER]` placeholders
4. Save your completed version in the relevant brand's section (not here)
5. If you improve a template, update it here and note the version

**Naming convention:** `TEMPLATE — [Brand/All] — [Use Case] — [Specific Name]`

## 📝 Cold Email Templates

### Initial Outreach

```
Subject: [First Name] — quick question about [Company]

Hi [First Name],

[Personalised first line — reference something specific: a post, news, growth signal]

We help [ICP description] achieve [specific outcome] — typically within [timeframe].

Would it make sense to have a 15-minute call this week to explore if we can do the same for [Company]?

[Your name]
[Your title] | [Brand]
```

### Follow Up 1 (Day 3)

```
Subject: Re: [First Name] — quick question about [Company]

Hi [First Name],

Just following up on my note from [Day]. 

I know inboxes get busy — happy to keep it short. Would a 10-minute call this [Day] or [Day] work?

[Your name]
```

### Follow Up 2 (Day 7 — switch channel to LinkedIn)

```
Hi [First Name] — sent you an email last week about [topic]. Figured I'd try here in case email got buried.

[One-line value prop]. Worth a quick chat?
```

## 📋 Service Proposal Structure

1. **Cover page** — Client name, prepared by, date, version
2. **Understanding your challenge** — 1 paragraph showing you listened
3. **Our approach** — Methodology, phases, timeline
4. **Deliverables** — Specific outputs per phase
5. **Investment** — Pricing tiers (if applicable), payment terms
6. **Why us** — 3 proof points (case study, result, testimonial)
7. **Next steps** — Call to action + expiry date
8. **Terms** — Reference to engagement letter / NDA
