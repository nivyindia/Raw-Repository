# IT and Systems

| **Task** | **Process Steps** | **Frequency** | **Responsible Role** | **Report Generated** | **Checklist** | **KPI** |
| --- | --- | --- | --- | --- | --- | --- |
| System Maintenance | Monitor servers → Update software → Backup data | Weekly | IT Administrator | System Health Report | ☐ Backups done ☐ Updates installed | System uptime (%) |
| User Access Management | Approve requests → Create accounts → Revoke inactive accounts | As Needed | IT Support Lead | Access Control Report | ☐ Access granted ☐ Revoked | Unauthorized access incidents |
| Data Security Monitoring | Run vulnerability scans → Patch security holes | Monthly | IT Security Analyst | Security Audit Report | ☐ Scans done ☐ Patches applied | Security breach incidents |
| Hardware & Asset Management | Maintain inventory → Repair/replace faulty items | Monthly | IT Asset Manager | IT Asset Report | ☐ Inventory updated ☐ Faulty replaced | Asset downtime |
| Helpdesk Support | Receive tickets → Troubleshoot → Resolve | Daily | IT Support Executive | Helpdesk Ticket Report | ☐ Tickets logged ☐ Resolved | Average resolution time |
| Disaster Recovery Testing | Simulate outages → Test backups → Validate recovery speed | Quarterly | IT Manager | DR Test Report | ☐ Test run ☐ Issues fixed | Recovery time objective met |
