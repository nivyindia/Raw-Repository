# ✅ Phase 3 — Control Layer

This folder contains the full Control Layer for the Nivy VA system:

- **5 QC Checklists** (QC-001 through QC-005) — VAs complete before submitting any work
- **VA SLA Document** — time-bound rules for every output type
- **VA Communication System** — platform rules, response times, escalation matrix

> **Rule:** No work reaches Manager review without the relevant QC checklist completed first.
