# ⚙️ 8. EXECUTION FLOW (ENFORCED PIPELINE)

```
Task → SOP → Template → Output → QC → Report → KPI
```

## 🎯 Purpose

Standardize how work moves so **quality + speed remain consistent**.

---

## 🔁 Stage Definitions

- **Task**: Assigned work with deadline + owner
- **SOP**: Exact steps to execute
- **Template**: Ready asset to reduce thinking time
- **Output**: Deliverable (doc, creative, sheet, etc.)
- **QC**: Checklist-based validation by reviewer
- **Report**: Logged outcome (metrics, links, notes)
- **KPI**: Performance captured and tracked

---

## ⚠️ Rules

- No task without SOP (flag as gap)
- No output without QC
- No work counted without report

---
