# 🌍 📄 WEEKLY PERFORMANCE REPORT (INTERNATIONAL STANDARD)

---

## 🔹 1. Executive Summary (VERY IMPORTANT)

👉 This is what clients read first

- Key result of the week (1–2 lines)
- Major improvement or decline
- Focus area for next week

### Example:

“This week we generated 42 leads at a 18% lower cost. Focus next week is improving conversion rate through landing page optimization.”

---

## 🔹 2. Account Overview

- Client Name:
- Reporting Period:
- Services Covered:
- Account Manager:

---

## 🔹 3. Work Delivered

Clear visibility of execution:

- Content created & published
- Ad campaigns launched / optimized
- Funnel / landing page updates
- Tracking / technical updates

---

## 🔹 4. Key Performance Metrics

👉 Always show **comparison (WoW – Week over Week)**

| Metric | This Week | Last Week | Change |
| --- | --- | --- | --- |
| Leads Generated |  |  |  |
| Cost per Lead (CPL) |  |  |  |
| Clicks |  |  |  |
| Conversion Rate |  |  |  |
| Ad Spend |  |  |  |

---

## 🔹 5. Performance Insights (MOST IMPORTANT)

👉 Not data—**interpretation**

- What worked and why
- What underperformed and why
- Audience / creative insights
- Funnel or conversion observations

---

## 🔹 6. Optimization Actions Taken

- What changes were made
- Why those changes were made
- Expected outcome

---

## 🔹 7. Risks / Challenges

- Budget limitations
- Low conversion issues
- Platform constraints
- Delays or dependencies

---

## 🔹 8. Next Week Plan

- Clear action steps
- Testing strategy
- Optimization focus

# 🔥 INTERNATIONAL REPORTING PRINCIPLES

---

## 1. Don’t Just Show Data → Explain It

## 3. Focus on Business Impact

Leads, conversions, revenue—not just reach

## 4. Show Control & Strategy

Clients should feel:

👉 “These people know what they’re doing”

## 5. Keep It Clean & Structured

No clutter, no confusion
