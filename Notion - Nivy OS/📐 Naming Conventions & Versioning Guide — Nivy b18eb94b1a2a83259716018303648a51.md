## 🏷️ Page Naming Convention

**Format:** `[Emoji] [Brand] — [Page Name]`

| Content Type | Format | Example |
| --- | --- | --- |
| Department Page | [Emoji] [Brand] — [Dept Name] | 📊 Nivy Next — Marketing |
| Template | TEMPLATE: [Document Type] | TEMPLATE: Service Agreement |
| Meeting Notes | [YYYY-MM-DD] Meeting — [Topic] | 2026-05-01 Meeting — Quarterly Review |
| Draft | [DRAFT] [Page Name] | [DRAFT] Pricing Strategy 2026 |
| Strategy Doc | [Emoji] [Brand] — [Strategy Name] | 🎯 Nivy Jobs — Hiring Strategy 2026 |

## 🗄️ Database Naming Convention

- **All databases** use `lowercase_snake_case` with no spaces
- **Example:** `projects_database`, `clients_database`, `sop_database`
- Database **views** use Title Case: `Active Projects`, `By Brand`, `Board View`

## 🔢 Versioning System

**Format:** `v[Major].[Minor]`

| Change Type | Version Bump | Example |
| --- | --- | --- |
| Significant content updates | +0.1 (v1.0 → v1.1) | New section added to SOP |
| New document | Start at v1.0 | First version created |

**Where to track versions:**

- In the `company_documents_database` → Version property
- In the `sop_database` → Version property
- On the page itself → In the metadata table at the bottom
