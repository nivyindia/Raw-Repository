# Test Case Scenarios

Here are **short, high-impact A/B test case scenarios** you should run.

For B2B US markets, **8–10 tests max** is ideal (don’t overtest).

---

## ✅ Recommended: **8 Core Test Scenarios**

### 1️⃣ Subject Line (Most Important)

- **A:** “New buyers looking for your materials”
- **B:** “We have verified buyers ready to purchase”
    
    👉 Tests **urgency vs trust**
    

---

### 2️⃣ Value Framing

- **A:** “Get new buyers – we take fee only if deal closes”
- **B:** “Zero upfront cost. Pay only on successful deals”
    
    👉 Tests **ROI clarity**
    

---

### 3️⃣ Commission Transparency

- **A:** “Success fee applies (typically 10–30%)”
- **B:** “Revenue share discussed after buyer match”
    
    👉 Tests **early vs delayed disclosure**
    

---

### 4️⃣ CTA Language

- **A:** “Yes, I want buyer opportunities”
- **B:** “Show me active buyer demand”
    
    👉 Tests **direct vs curiosity**
    

---

### 5️⃣ Social Proof

- **A:** No proof
- **B:** “Suppliers across US construction & roofing already use this”
    
    👉 Tests **credibility boost**
    

---

### 6️⃣ Email Length

- **A:** Ultra-short (4–5 lines)
- **B:** Short + 3 bullet points
    
    👉 Tests **speed readers vs detail seekers**
    

---

### 7️⃣ Sender Identity

- **A:** Company name (Nivy Alliance)
- **B:** Person + company (Abhishek | Nivy Alliance)
    
    👉 Tests **human vs brand trust**
    

---

### 8️⃣ Reminder Tone (Follow-Up Email)

- **A:** “Quick reminder – buyer demand this month”
- **B:** “Closing buyer shortlist this week”
    
    👉 Tests **soft vs urgency**
    

---

## 🚫 Tests You Should NOT Run (Yet)

- Too many CTAs
- Community / Telegram in first email
- Pricing breakdown tables
- Long case studies in cold outreach

---

## 🎯 Rule of Thumb

- **Run max 2 tests at a time**
- Lock winners before moving to next test
- Measure: **Reply + CTA click**, not opens only

### ✅ **Standard Email Testing Method (Best Practice)**

**Do NOT create separate campaigns.**

Test **inside the SAME campaign** using A/B variants.

---

### 🔹 How to Test (Simple Method)

1. **One variable at a time**
    - Example: Subject line OR CTA (never both together)
2. **Same campaign → Variant emails**
    - Email O1 → Version A & Version B
    - Mautic auto-splits traffic (50/50 or 70/30)
3. **Minimum sample size**
    - At least **500–1,000 contacts per variant**
    - Otherwise results are unreliable
4. **Measure the RIGHT metric**
    - Primary: **CTA click / reply**
    - Secondary: open rate
    - Ignore vanity metrics
5. **Lock winner**
    - Stop losing variant
    - Use winner for 100% traffic
6. **Then test next variable**
    - Subject → CTA → Value framing → Reminder tone

---

### 🔹 Testing Order (Recommended)

1️⃣ Subject line

2️⃣ Value proposition

3️⃣ CTA wording

4️⃣ Reminder urgency

5️⃣ Commission disclosure timing

---

### 🚫 What NOT to Do

❌ Separate campaigns for same audience

❌ Multiple changes in one test

❌ Testing without enough volume

---

### 🧠 Golden Rule

**One campaign → one audience → one variable → one decision**

This keeps your data clean and scalable.
