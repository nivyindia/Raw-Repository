## 📝 Core Prompts

### SOP Writer

```
You are an expert business operations consultant. Write a detailed Standard Operating Procedure (SOP) for [TASK NAME] at [BRAND NAME].

Context:
- Brand: [BRAND]
- Department: [DEPARTMENT]
- Role executing this SOP: [ROLE]
- Frequency: [DAILY / WEEKLY / AS NEEDED]
- Tools used: [LIST TOOLS]

Format the SOP with:
1. Purpose
2. Scope (who this applies to)
3. Pre-requisites (what you need before starting)
4. Step-by-step instructions (numbered, specific, no assumptions)
5. Quality standard (how do you know it's done right?)
6. Common mistakes to avoid
7. Escalation path (what to do if something goes wrong)

Write for someone doing this task for the first time.
```

### Cold Email Writer

```
Write a cold outreach email for [BRAND NAME] targeting [TARGET COMPANY / ROLE].

Context:
- Our service: [WHAT WE DO]
- Their likely pain point: [PAIN]
- Desired outcome of the email: [BOOK A CALL / REPLY / DOWNLOAD]
- Tone: [PROFESSIONAL / CONVERSATIONAL / DIRECT]
- Length: Max 100 words

Requirements:
- Personalised first line referencing [SPECIFIC DETAIL]
- One clear value statement
- One low-friction CTA
- No buzzwords or generic phrases like "I hope this finds you well"

Write 3 variations with different angles.
```

### ICP Profiling

```
Create a detailed Ideal Customer Profile (ICP) for [BRAND NAME].

Service offered: [DESCRIBE SERVICE]
Target market: [REGION / INDUSTRY]

Provide:
1. Firmographic profile (industry, size, revenue, location, growth stage)
2. Decision maker profile (title, seniority, typical background)
3. Psychographic profile (goals, fears, values, priorities)
4. Pain points (ranked by urgency)
5. Trigger events (what makes them likely to buy NOW)
6. Where to find them (channels, platforms, communities)
7. Disqualifying signals (who is NOT a fit)

Be specific. Avoid generic answers. Use data where possible.
```

### LinkedIn Post Writer

```
Write a LinkedIn post for [BRAND / PERSONAL] on the topic of [TOPIC].

Goal: [AWARENESS / LEAD GEN / THOUGHT LEADERSHIP / ENGAGEMENT]
Target audience: [WHO WILL READ THIS]
Tone: [PROFESSIONAL / STORYTELLING / CONTRARIAN / EDUCATIONAL]
Length: [SHORT (under 150 words) / MEDIUM (150–300) / LONG (300–600)]

Requirements:
- Hook: First line must stop the scroll
- No corporate jargon
- Ends with a question or clear CTA
- Include 3–5 relevant hashtags at the end

Write 2 versions with different hooks.
```
