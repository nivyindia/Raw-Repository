## 🌐 **1. Website Performance & Technical Health**

### 🧰 **Tools**

| Tool | Purpose | What to Check |
| --- | --- | --- |
| **Google PageSpeed Insights** | Site loading speed (mobile + desktop) | - Load time < 3s  - Core Web Vitals (LCP, FID, CLS)  - Image & script optimization |
| **GTmetrix** | Deeper performance report | - Overall grade (A/B)  - Server response time  - Caching setup |
| **Google Search Console** | SEO + indexing issues | - Page indexing status  - Mobile usability  - Core web vital issues |
| **Ahrefs / SEMrush / Ubersuggest** | Overall SEO audit | - Technical errors  - Broken links  - Duplicate pages  - Missing metadata |
| **Screaming Frog SEO Spider** | Deep technical crawl | - Redirects, canonical tags, noindex pages, schema |
| **SSL Labs** | Website security test | - SSL grade “A” minimum  - Expiry alerts |
| **Google Analytics 4** | User flow & behavior | - Bounce rate < 45%  - Avg. session > 1.5 min  - Top pages traffic |
