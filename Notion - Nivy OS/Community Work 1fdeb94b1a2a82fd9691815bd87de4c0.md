# 🧠 SKILL LEVEL DEFINITIONS (Use This Everywhere)

### 🔹 Zero Skill (Z0)

- No prior knowledge
- Can follow instructions
- Works only with scripts/templates

### 🔹 Skill Level-1 (L1)

- 7–15 days training
- Understands tools
- Can execute repetitive technical tasks

### 🔹 Skill Level-2 (L2)

- 30–60 days experience
- Can review juniors
- Can handle clients & quality checks
- Still **no final authority**
