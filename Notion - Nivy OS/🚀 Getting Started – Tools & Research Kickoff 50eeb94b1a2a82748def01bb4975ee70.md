
# 🔵 **2. Use “Tagging System” in File Names to Make Search Easy**

Add **#tags** inside file names to make search work even if you forget names.

Example:

```
ACME — Marketing — Email Strategy — Lead Nurture — 2025-10-01 #email #strategy #automation

```

Now even if you search:

- “email”
- “nurture”
- “strategy”
- the client name
- the date
- or one tag

→ the file will appear.

You can add:

- #sop
- #post
- #invoice
- #proposal
- #video
- #clientname
- #creative
- #report
- #research

This removes 100% dependency on memory.
