# 📐 Phase 5 — Rules We Will Follow

> These are the non-negotiable rules that we follow throughout every session of this restructuring. If anyone is unsure about what to do, check these rules first.
> 

> 📍 **Where you are:** Knowledge Base Restructuring Plan → Phase 5 | Completed: April 2026
> 

---

## 🔒 The 10 Rules

### Rule 1: Never Delete Anything

❌ Do not delete any page, subpage, database, or database entry

✅ If something is outdated or redundant, move it to the Archive section of its teamspace

---

### Rule 2: Never Change Information

❌ Do not modify the actual body content of existing pages (the written information)

✅ You may add new callouts, navigation blocks, or intro sections at the TOP of a page

✅ You may fix typos in titles only if very obvious

---

### Rule 3: Ask Before Renaming

❌ Do not rename pages without logging the change

✅ Before renaming, note the old name and new name in a "Rename Log" comment on that page

✅ Rename only when it makes the page significantly clearer

---

### Rule 4: Add Context, Don’t Replace It

❌ Do not rewrite pages that already have content

✅ Add a callout block at the TOP of the page to explain what it is

✅ The original content stays exactly as it is, below the callout

---

### Rule 5: Keep One Source of Truth

❌ Do not duplicate pages (e.g., "Company Overview" in 3 places)

✅ Choose the primary version and add a note on the duplicates linking to the primary

✅ If uncertain which is primary, leave both and flag for review

---

### Rule 6: Follow the Naming Convention

❌ Do not create pages with generic names ("Notes", "Plan", "Overview")

✅ Use the format: [Emoji] [Descriptive Name] — [Context if needed]

✅ Examples: "📊 Sales Dashboard — Q1 2026", "💼 SOP: Client Onboarding"

---

### Rule 7: Every Home Page Gets a "What is this?" Callout

❌ Do not leave teamspace home pages with Notion’s default placeholder content

✅ Every home page must have a callout explaining what the teamspace is and who it’s for

✅ Minimum content: What is this? | What does it contain? | Who should use it?

---

### Rule 8: Log Every Change

❌ Do not make changes without recording what was done

✅ After each session, update the Execution Checklist in Phase 4 to mark completed tasks

✅ If something unexpected comes up, add a note to the relevant phase page

---

### Rule 9: Shell Teamspaces Get Placeholder Pages, Not Empty Shells

❌ Do not leave future teamspaces (Academy, Alliance, Care, Digital HQ) completely empty

✅ Every shell teamspace gets a simple home page saying what it will be and when it’s being built

✅ This prevents confusion when a new member stumbles upon it

---

### Rule 10: The Start Here Page is the North Star

❌ Do not start any restructuring session without first reviewing the Start Here page plan

✅ Every decision should pass the test: "Would a new person understand this from the Start Here page?"

✅ If yes, it’s consistent. If no, we need to revise.

---

## 🚨 What to Do If You’re Unsure

1. Stop and re-read this Rules page
2. If still unsure, do NOT make the change
3. Add a comment to the relevant page with your question
4. Raise it in the next team check-in

> The worst thing we can do is make a change that looks like an improvement but breaks something someone was relying on. When in doubt, don’t.
