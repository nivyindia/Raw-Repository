# 🔧 Freelancer Automation Hiring & Onboarding

# 🤖 HOW TO AUTOMATE YOUR FREELANCER TEAM (START → SCALE)

We’ll automate **5 things**:

1. Hiring & filtering
2. Testing & evaluation
3. Onboarding & SOP delivery
4. Work tracking & performance
5. Payment & scaling decisions

All with **low-cost / free tools**.

---

## PHASE 1: AUTOMATED HIRING & FILTERING

### 1️⃣ Create ONE Master Application Form (Google Form)

This replaces manual screening.

Include:

- Name, country, timezone
- Primary niche (only ONE allowed)
- Years of experience
- Fiverr / Upwork / LinkedIn profile links
- Portfolio / case studies
- Tools they use
- Willingness to do paid sample work (Yes/No)
- Understanding of performance-based work (Yes/No)

👉 Add **required fields + dropdowns**

👉 Reject generalists automatically

✅ Result: 70% low-quality people filtered instantly

---

### 2️⃣ Auto-Screen with Conditional Logic

Use Google Form logic:

- If they select **multiple niches** → auto-reject page
- If experience < 2 years → auto-reject page
- If “No” to sample work → auto-reject page

This saves **hours every week**.

---

### 3️⃣ Auto-Sort Applicants

Connect Google Form → Google Sheet

Add columns:

- Status (New / Rejected / Shortlisted / Trial)
- Score (manual or formula-based)
- Niche tag

You now have a **living freelancer database**.

---

## PHASE 2: AUTOMATED TEST / SAMPLE WORK

### 4️⃣ Auto-Assign Sample Tasks

For each niche, create:

- One **Sample Task Doc**
- One **Submission Form**

Example:

- Lead Gen → “Generate 50 leads”
- Design → “Create 2 creatives”
- Sales → “Book 1 demo”

When you change status to **“Trial”**:

- Send sample task link
- Set deadline automatically (date field)

👉 No custom explanations needed every time.

---

### 5️⃣ Automated Evaluation Sheet

Create a simple scoring system:

| Criteria | Score (1–5) |
| --- | --- |
| Quality |  |
| SOP following |  |
| Communication |  |
| Speed |  |
| Ownership |  |

Formula auto-calculates:

- **Pass / Fail**
- Performance %

Set rule:

- <65% → auto reject
- ≥65% → move to onboarding

---

## PHASE 3: AUTOMATED ONBOARDING

### 6️⃣ Central SOP Library (Read-Only)

Create one Notion / Google Drive folder:

Folders like:

- Lead Gen SOPs
- Outreach SOPs
- Sales SOPs
- Delivery SOPs
- Reporting SOPs

On approval:

- Share **only relevant SOP folder**
- No access to everything

👉 This prevents confusion + data leaks.

### 7️⃣ Auto-Role Assignment

Use a tracker:

| Freelancer | Role | SOP Link | Manager | Start Date |
| --- | --- | --- | --- | --- |

This becomes your **command center**.

## PHASE 4: WORK & PERFORMANCE AUTOMATION

### 8️⃣ Daily / Weekly Reporting Automation

Each role submits via **Google Form**:

Examples:

- Leads generated
- Emails sent
- Calls made
- Deals closed
- Issues faced

Form → Sheet → Dashboard

You never ask:

### 9️⃣ KPI Dashboard (Auto)

Use Google Sheets formulas:

- % achievement
- Bonus eligibility
- Warning flags

Rules:

- <65% = warning
- <65% for 2 cycles = removal
- 
    
    > 100% = bonus candidate
    > 

Decisions become **data-based, not emotional**.

No confusion. No disputes.

This lets you scale **without thinking daily**.

- Freelancer task flow (Bitrix24)
- SOP enforcement
- Deadline tracking
- Issue escalation

**KPIs:**

- Delivery on time
- SOP compliance
- Freelancer retention

**Where to get:**

- Promote best senior freelancer (6–8 weeks performance)
- Ex‑agency project manager

---

### 2️⃣ Sales Manager / Deal Closure Head

**Role:** Owns revenue & deal closure

**Handles:**

- Sales freelancers / partners
- Call reviews & scripts
- Deal conversion %

**KPIs:**

- Close rate
- Revenue per month
- Sales cycle length

**Where to get:**

- Promote top closer

### 3️⃣ Delivery / Quality Control Manager
