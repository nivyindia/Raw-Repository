### 🧠 2. SYSTEM CONNECTION MAP (Cross-Department Flow)

```
[STRATEGY SYSTEM]
     ↓ defines
[OBJECTIVES & OKRs]
     ↓ guides
[OPERATIONS SYSTEM] → produces → [DATA]
     ↓ feeds
[ANALYTICS SYSTEM] → insights → [STRATEGY SYSTEM]
     ↓ triggers
[HR SYSTEM] → trains → [PEOPLE]
     ↓ supports
[SALES SYSTEM] → interacts → [CUSTOMERS]
     ↓ generates
[FINANCE SYSTEM] → records → [DATA SYSTEM]
```

This one shows how systems feed each other (looped relationships).
