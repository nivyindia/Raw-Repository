## 📝 Caterer ke saath baat karte waqt ye zaroor pooche

- [ ]  Per plate rate kya hai (veg / non-veg alag-alag)?
- [ ]  Bartan (plates, glasses, serving vessels) include hain ya alag?
- [ ]  Waiter / helper include hain?
- [ ]  Gas / stove ka arrangement kaun karega?
- [ ]  Khana venue par banayenge ya laakar denge?
- [ ]  Timing kya hoga (chai-nashta, lunch, dinner)?
- [ ]  Leftover khane ka kya karenge?
- [ ]  Cancellation policy kya hai?
- [ ]  Advance kitna dena hoga?

## 🔍 Quality Check SOP (Khane ka)

- [ ]  Caterer se menu tasting karle shadi se pehle
- [ ]  Masala / tel ki matra confirm kare (ghar ke taste ke hisaab se)
- [ ]  Halal / special dietary requirements check kare
- [ ]  Ek trusted vyakti ko khane ki supervision de shadi ke din
- [ ]  Khana kitni baar serve hoga ye confirm kare
- [ ]  Serving table ka layout decide kare
