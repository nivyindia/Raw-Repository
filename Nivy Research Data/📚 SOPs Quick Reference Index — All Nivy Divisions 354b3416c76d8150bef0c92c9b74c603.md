## 🔍 How to Use This Page

- **Browsing?** Use the division sections below to find SOPs for your team
- **Searching?** Use `Ctrl+F` / `Cmd+F` to find by keyword
- **Database filter?** Go to [sop_database](https://www.notion.so/29bb3416c76d80b193edf449eb4ff961) and filter by Brand or Department
- **Creating a new SOP?** Name it: `SOP: [Action Verb] [Subject]` — see [Naming Conventions Guide](https://www.notion.so/354b3416c76d81d9bc98ce2d50c06924)

## ➕ How to Add a New SOP to This Index

1. Write the SOP as a page in the relevant division teamspace
2. Add it to the **sop_database** with correct Brand + Department + Status
3. Add a row to the appropriate section in this index
4. Follow naming convention: `SOP: [Action Verb] [Subject]`
