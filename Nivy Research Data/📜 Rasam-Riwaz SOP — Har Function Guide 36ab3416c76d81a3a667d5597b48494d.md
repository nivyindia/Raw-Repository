## 🪷 1. Tilak / Roka

**Matlab:** Ladke wale ladki ke ghar jaate hain, tilak lagakar rishta pakka karte hain

**Kya chahiye:**

- [ ]  Tilak ki thali (chawal, kumkum, supari, paise, kapde, mithai)
- [ ]  Shagun ka lifafa
- [ ]  Mewa / Dry fruits
- [ ]  Dulhe ke liye kapde (Dulhan side se)
- [ ]  Mithai (multiple varieties)
- [ ]  Camera / photographer

**SOP:**

1. Ladke wale nimantran lekar aate hain
2. Bade log baithte hain
3. Pandit ji (agar ho) rasam karwate hain
4. Tilak lagaya jaata hai
5. Shagun diya jaata hai
6. Khana-peena

---

## 🌿 2. Haldi (Ubtan)

**Matlab:** Shubh shuruwat — haldi lagakar bura nazar se bachana

**Kab:** Shadi se 1-2 din pehle (Dulhe aur Dulhan ke alag-alag ghar mein)

**Kya chahiye:**

- [ ]  Haldi powder (500g+)
- [ ]  Ubtan (besan + haldi + gulabjal + malai)
- [ ]  Sarson / Nariyal tel
- [ ]  Peetha (bajra / gehu ka atta)
- [ ]  Yellow kapde (dulhe/dulhan ke liye)
- [ ]  Peetha baithne ke liye (wooden stool)
- [ ]  Flowers / petals for decoration
- [ ]  Diya aur thali
- [ ]  Old towel / chadar (jo khraab ho)
- [ ]  Camera / photographer

**SOP:**

1. Dulha / Dulhan peethe par baithe
2. Puja / diya jalaya
3. Maa sabse pehle haldi lagaye
4. Phir relatives baar-baar lagaayein
5. Haldi lagane ke baad nahaye nahi (kuch ghante)
6. Photos zaroor le

---

## 🎨 3. Mehendi

**Matlab:** Dulhan ke haath-pair mein mehendi — shaadi ka rang

**Kab:** Shadi se 1 din pehle (raat ko)

**Kya chahiye:**

- [ ]  Mehendi artist booked (Vendors page dekhe)
- [ ]  Design photos ready (show karne ke liye)
- [ ]  Mehendi cones (backup)
- [ ]  Seating arrangement (floor seating)
- [ ]  Lighting proper ho
- [ ]  Snacks aur pani
- [ ]  Tissue / cotton
- [ ]  Lemon + sugar (mehendi set karne ke liye)
- [ ]  Music / playlist

**SOP:**

1. Artist aaye, design decide kare
2. Dulhan pehle, phir relatives
3. Haath + pair dono
4. Mehendi sookne mein 4-6 ghante
5. Sookne ke baad lemon-sugar lagaye
6. Raat bhar rehne de, subah hataye

> 💡 **Tip:** Dulhan ke haath mein dulhe ka naam chupaaya jaata hai — photographer se special shot lo!
> 

---

## 🎵 4. Sangeet

**Matlab:** Gaana-bajaana, dance, entertainment — khaandaani masti

**Kab:** Shadi se 1 din pehle (ya mehendi ke saath)

**Kya chahiye:**

- [ ]  DJ / Music system (Vendors page dekhe)
- [ ]  Songs playlist ready kare
- [ ]  Performances plan (kaun kya perform karega)
- [ ]  Stage / dance floor
- [ ]  Costume for performances (agar ho)
- [ ]  Microphone
- [ ]  Gifts for performers (agar ho)

---

## 👑 5. Sehra / Baraat

**Matlab:** Dulha sehra pahankar dulhan ke ghar jaata hai

**Kab:** Shadi ke din

**Kya chahiye:**

- [ ]  Sehra (phoolon ka)
- [ ]  Ghodi / Car / Horse
- [ ]  Band-Baja (Vendors page dekhe)
- [ ]  Dulha ke kapde, pagdi ready
- [ ]  Baraat mein jaane wale log confirm
- [ ]  Baraat route decide
- [ ]  Mithai / thaali for welcome

**SOP:**

1. Dulha tayaar ho
2. Sehra ceremony (ghar pe)
3. Ghodi / car pe baithna
4. Band ke saath nikalna
5. Dulhan ke ghar / venue pahunchna
6. Swagat (dulhan side waale karte hain)

---

## 💐 6. Jai Mala (Varmala)

**Matlab:** Dulha-Dulhan ek doosre ko mala pahenate hain

**Kya chahiye:**

- [ ]  Do maalayen (Flower mala) ready
- [ ]  Stage / special area
- [ ]  Family to hold back baraat members (maasti ke liye!)
- [ ]  Photographer alert kare

---

## 🔥 7. Saat Pheras

**Matlab:** Agni ke saath 7 phere lekar shaadi mukammal hoti hai

**Kab:** Muhurat ke hisaab se (Pandit ji se confirm)

**Kya chahiye:**

- [ ]  Havan kund ready
- [ ]  Havan samagri (Pandit ji se list lo)
- [ ]  Lakdi / kande
- [ ]  Ghee (minimum 500g)
- [ ]  Mangalsutra (Dulha rakhega)
- [ ]  Sindoor
- [ ]  Kalash with water
- [ ]  Paan, supari, naariyal
- [ ]  Chunri / red dupatta
- [ ]  Pandit ji ka aasan

**SOP:**

1. Pandit ji havan shuru karenge
2. Kanyadaan rasam
3. Hasta Milan (haath pakadna)
4. 7 phere (Pandit ji mantra padhenge)
5. Sindoor / Mangalsutra
6. Ashirwad

---

## 🙏 8. Kanyadaan

**Matlab:** Dulhan ke pitaji dulhan ka haath dulhe ko dete hain

**Kab:** Pheron ke beech

**Kya chahiye:**

- [ ]  Kalash with water (Papa ka haath)
- [ ]  Pandit ji guide karenge
- [ ]  Photographer alert (emotional moment)

---

## 👋 9. Vidai

**Matlab:** Dulhan apne ghar se bidaai leti hai

**Kab:** Pheron ke baad

**Kya chahiye:**

- [ ]  Doli / decorated car ready
- [ ]  Chawal (dulhan peeth peeche fenke)
- [ ]  Phoolon ki varsha
- [ ]  Tissue / handkerchief (sab rone wale hain!)
- [ ]  Photographer aur videographer alert kare

**SOP:**

1. Ashirwad ceremony
2. Dulhan sab se mili
3. Chawal uchhal ke fenke
4. Car mein baith ke gai
5. **Photographer: ye pura shot lo — bohot emotional hota hai!**

---

## 🎉 10. Reception / Dawat

**Matlab:** Naye jodon ka public welcome, gifts, photos

**Kab:** Shadi ke agले din / shaam

**Kya chahiye:**

- [ ]  Venue arrange
- [ ]  Dulha + Dulhan ka special outfit
- [ ]  Stage / photo zone
- [ ]  Khana / Dawat
- [ ]  DJ / Music
- [ ]  Guest list (naye log bhi aa sakte hain)
- [ ]  Gifts collect karne ki jagah

---

## ⚠️ Rasam ke liye Important Tips

> 1. **Pandit ji se puri list lo** — har pandit ki apni list hoti hai
> 

> 2. **Ek din pehle saaman check kare** — last minute na bhaagein
> 

> 3. **Har rasam ke liye ek responsible person tay kare**
> 

> 4. **Photographer ko list de** — kaunsi rasam mein kon sa shot chahiye
> 

> 5. **Time buffer rakhein** — rasme time se late hoti hain
>
