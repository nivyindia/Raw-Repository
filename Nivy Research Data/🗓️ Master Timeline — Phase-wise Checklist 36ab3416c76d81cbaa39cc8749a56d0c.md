# 🗓️ Master Timeline — Phase-wise Checklist

> शादी की तारीख से उलटा गिनते हुए हर महीने क्या करना है — एक भी काम miss नहीं होगा। हर task के साथ responsible person का नाम लिखें।
> 

---

## 🔴 Phase 1 — 6+ महीने पहले (नींव रखना)

### 🏠 Venue & Dates

- [ ]  शादी की तारीख और मुहूर्त tay करें (Pandit ji से milkar)
- [ ]  Venue decide करें — Ghar / Marige Hall / Farmhouse
- [ ]  Venue advance booking और receipt लें
- [ ]  Haldi, Mehendi, Sangeet की dates tay करें
- [ ]  Approximate guest count parivar se milkar tay kare

### 💰 Budget

- [ ]  Total budget tay kare (parivar ke saath baithkar)
- [ ]  Budget को categories mein baante — Budget Tracker page dekhe
- [ ]  Paise kahan se aayenge — savings, loan, relatives — plan kare

### 📞 Key Vendors (Advance Booking)

- [ ]  Caterer se milkar tentative booking kare
- [ ]  Photographer / Videographer book kare (popular wale jaldi bhar jaate hain)
- [ ]  Decorator se baat kare — theme aur design decide kare
- [ ]  Band-Baja / DJ book kare
- [ ]  Tent / Shamiyana wale se contact kare
- [ ]  Pandit ji ko confirm kare

### 👨‍👩‍👧‍👦 Family

- [ ]  Dono taraf ke parivar mein confirm kare
- [ ]  Main responsible person tay kare (coordinator)
- [ ]  Relatives ki list banana shuru kare

---

## 🟠 Phase 2 — 3-4 महीने पहले (Planning सुदঃढ़ करना)

### 📜 Guest List

- [ ]  Pura guest list final kare — Guest List page dekhe
- [ ]  Dono taraf (Dulha + Dulhan) ki list alag-alag banaye
- [ ]  Bahar se aane wale relatives ki list alag kare
- [ ]  Approximate headcount caterer ko de

### 📫 Invitation Cards

- [ ]  Card design tay kare (designer se ya printing press se)
- [ ]  Card mein likhe: Naam, Date, Time, Venue, Contact number
- [ ]  Sample proof check kare pehle
- [ ]  Printing order de — 10-15% extra print kare
- [ ]  **Distribution plan banaye** — kaun-kaun cards leke jayega
- [ ]  Online invitation (WhatsApp) ke liye design banaye

### 👗 Shopping

- [ ]  Dulhan ka lehenga / saree shopping shuru kare
- [ ]  Dulha ka sherwani / suit
- [ ]  Jewellery list banaye aur khareedari shuru kare
- [ ]  Relatives ke kapde (parents, siblings)

### 🍽️ Catering

- [ ]  Menu final kare — Catering page dekhe
- [ ]  Per plate rate confirm kare
- [ ]  Advance payment kare aur receipt le

### 🏠 Venue Arrangements

- [ ]  Bijli / Generator arrangement kare
- [ ]  Parking ki jagah tay kare
- [ ]  Bahar se aane wale relatives ka accommodation
- [ ]  Venue ka rough layout banana (kahan kya hoga)

---

## 🟡 Phase 3 — 1-2 महीने पहले (Confirm & Finalize)

### 📨 Invitation Distribution

- [ ]  Cards ready hone par distribution shuru kare
- [ ]  City mein khud jaake dene ki list
- [ ]  Post / courier se bahar bhejne ki list
- [ ]  WhatsApp invitation send kare
- [ ]  RSVP track kare — Guest List page update karte rahe
- [ ]  Jo card nahi mila unhe reminder call kare

### ✅ Vendor Confirmations

- [ ]  Sabhi vendors ko confirm call kare
- [ ]  Catering ko final headcount de
- [ ]  Decorator ko final design approve kare
- [ ]  Photographer ko shot list de
- [ ]  Band / DJ ko song list de
- [ ]  Tent wale ko layout diagram de

### 📜 Rasam Planning

- [ ]  Sabhi rasam ki list banaye — Rasam SOP page dekhe
- [ ]  Har rasam ke liye saaman list ready kare
- [ ]  Pandit ji se schedule confirm kare

### 🛒 Shopping Complete

- [ ]  Sari shopping complete kare
- [ ]  Puja saaman khareedna shuru kare
- [ ]  Gifts / return gifts khareedna
- [ ]  Makeup trial le
- [ ]  Stitching / fitting final kare

---

## 🟢 Phase 4 — 1 हफ्ते पहले (Last Mile)

### 📞 Final Calls

- [ ]  Har vendor ko ek baar phone kare — time, date, venue confirm
- [ ]  Pandit ji ko puri rasam ka schedule de
- [ ]  Photographer ko venue ka walkthrough karaye (agar possible ho)
- [ ]  Caterer ko last headcount de

### 💰 Finance

- [ ]  Vendors ki balance payment ke liye cash ready kare
- [ ]  Shagun envelopes ready kare
- [ ]  Tips ke liye chhutte paise (band, baraat, helpers)
- [ ]  Total budget status check kare

### 🏠 Venue & Setup

- [ ]  Venue ki cleaning kare
- [ ]  Decoration team ko access de
- [ ]  Generator / bijli backup check kare
- [ ]  Parking arrangement check kare
- [ ]  Shamiyana / tent setup shuru kare

### 👨‍👩‍👧‍👦 Family Duties Assign

- [ ]  Baraat mein kaun-kaun jayega
- [ ]  Swagat kaun karega
- [ ]  Guest handling kaun karega
- [ ]  Catering coordination kaun karega
- [ ]  Photographer ko guide kaun karega
- [ ]  Vidai mein kaun karega arrangements

### 🛒 Packing & Ready

- [ ]  Dulhan ke kapde, jewellery, makeup — ek jagah pack kare
- [ ]  Dulha ke kapde, pagdi, shoes — ek jagah ready
- [ ]  Puja saaman ek dabbey mein pack kare
- [ ]  First Aid kit ready kare
- [ ]  Emergency kit: safety pins, needle-thread, stain remover

---

## 🟣 Phase 5 — शादी से 1 दिन पहले (Pre-Wedding Eve)

- [ ]  Mehendi function complete kare
- [ ]  Sangeet / Antakshari (agar ho)
- [ ]  Dulha + Dulhan dono achi neend le
- [ ]  Subah ke liye alarm set kare
- [ ]  Sab kapde press / steam kare
- [ ]  Puja ki thali ek jagah rakh le
- [ ]  Photographer ko next day schedule remind kare
- [ ]  Sabhi vendors ko ek baar WhatsApp kare

---

## 🔴 Phase 6 — शादी का दिन

> **Day-of SOP ke liye alag page dekhe 👉 🗓️ शादी के दिन का Plan**
> 

---

## 📅 Post-Wedding (Agle 1-2 din)

- [ ]  Vendors ko final payment kare
- [ ]  Gifts / shagun count kare
- [ ]  Photographer ko raw files backup reminder de
- [ ]  Venue ki cleaning arrange kare
- [ ]  Rented saaman return kare (bartan, chairs, etc.)
- [ ]  Thank you calls / messages relatives ko
- [ ]  Jo log nahi aa sake unhe bhi inform kare
