## 📋 Phase-wise Master Checklist

### 🗓️ Phase 1 — 6 महीने पहले

- [ ]  शादी की तारीख और मुहूर्त तय करें (पंडित से मिलें)
- [ ]  शादी का venue book करें (घर / मैरेज हॉल / फार्महाउस)
- [ ]  लगभग कितने मेहमान होंगे — अनुमान लगाएं
- [ ]  कुल budget तय करें (परिवार के साथ बैठकर)
- [ ]  Caterer से बात करें और tentative booking करें
- [ ]  Photographer / Videographer book करें
- [ ]  Decorator से बात करें — theme और design decide करें
- [ ]  Band-Baja / DJ book करें
- [ ]  Tent / Shamiyana wale से contact करें
- [ ]  दोनों तरफ के परिवार में रिश्तेदारों की सूची बनाएं
- [ ]  Pandit ji को confirm करें

### 🗓️ Phase 2 — 3 महीने पहले

- [ ]  Dulha और Dulhan के सभी कपड़े (lehenga, sherwani, etc.) की shopping शुरू करें
- [ ]  Gold / Jewellery की list बनाएं और खरीदारी शुरू करें
- [ ]  Wedding card design तय करें और printing order दें
- [ ]  Guest list final करें — total count confirm करें
- [ ]  Catering menu final करें (breakfast, lunch, dinner, snacks)
- [ ]  Decoration का final plan बनाएं (mandap, entrance, stage)
- [ ]  Accommodation arrange करें बाहर से आने वाले मेहमानों के लिए
- [ ]  Mehndi wali / Beauty parlour book करें
- [ ]  Wedding के लिए गाड़ियां (baraat, doli) arrange करें
- [ ]  DJ / Band का song list तय करें
- [ ]  Invitation cards distribute करना शुरू करें

### 🗓️ Phase 3 — 1 महीना पहले

- [ ]  सभी vendors को confirm call करें
- [ ]  Final guest list ready करें — RSVP लें
- [ ]  Catering को final headcount दें
- [ ]  Rasam-Riwaz की list बनाएं — कौन सी रस्म कब होगी
- [ ]  हर रस्म के लिए जरूरी सामान की list बनाएं
- [ ]  Pandit ji से rasam schedule confirm करें
- [ ]  Baraat route plan करें
- [ ]  Makeup trial करें
- [ ]  Sone चांदी / gifts की shopping complete करें
- [ ]  Shaadi mein entertainment (game, sangeet) plan करें
- [ ]  घर की सफाई और decoration plan बनाएं
- [ ]  Hotel / Suhaag raat का arrangement करें (अगर जरूरी हो)

### 🗓️ Phase 4 — 1 हफ्ते पहले

- [ ]  सभी vendors को final confirmation दें
- [ ]  Catering को exact menu और quantity confirm करें
- [ ]  Photographer को shot list दें (कौन-कौन से moments capture करने हैं)
- [ ]  घर / venue की final cleaning और decoration शुरू करें
- [ ]  सभी कपड़े, jewellery, makeup items एक जगह रखें
- [ ]  Pandit ji को all puja saaman list दें
- [ ]  बाहर से आने वाले मेहमानों का reception arrange करें
- [ ]  Cash / Envelope arrangements करें (shagun, tips, etc.)
- [ ]  Mehendi ki function plan final करें
- [ ]  Haldi function plan final करें
- [ ]  Family ko responsibilities assign करें

### 🗓️ Phase 5 — शादी का दिन (SOP)

**सुबह:**

- [ ]  Pandit ji को inform करें — timing confirm करें
- [ ]  Dulha / Dulhan की haldi और makeup शुरू करें
- [ ]  Catering team को setup करवाएं
- [ ]  Decorator को final touches के लिए बुलाएं
- [ ]  Band / DJ को arrive करवाएं
- [ ]  Photographer / Videographer brief करें

**Baraat के समय:**

- [ ]  Dulha तैयार हो जाए — photo session
- [ ]  Baraat निकले — Band के साथ
- [ ]  Swagat / Tikka ceremony
- [ ]  Jai Mala

**Pheras और Vidai:**

- [ ]  Mandap puja शुरू करें — Pandit ji के साथ
- [ ]  Saat Pheras
- [ ]  Sindoor / Mangalsutra
- [ ]  Ashirwad ceremony
- [ ]  Vidai — emotional moment — Photographer alert!

**बाद में:**

- [ ]  Vendors को final payment करें
- [ ]  Gifts और shagun count करें
- [ ]  Photographer को raw files backup के लिए remind करें

## 📜 Rasam-Riwaz SOP

### 🌿 हल्दी (Haldi)

**कब:** शादी से 1-2 दिन पहले

**कौन करता है:** परिवार के सदस्य

**जरूरी सामान:**

- [ ]  हल्दी पाउडर (कम से कम 500 ग्राम)
- [ ]  तेल (सरसों / नारियल)
- [ ]  उबटन (besan + हल्दी + गुलाबजल)
- [ ]  पीले कपड़े
- [ ]  फूल और पत्तियां
- [ ]  थाली और दीपक

### 🎨 मेहंदी (Mehendi)

**कब:** शादी से 1 दिन पहले (रात को)

**जरूरी सामान:**

- [ ]  Mehendi artist book करें
- [ ]  बैठने की व्यवस्था
- [ ]  Light / decoration
- [ ]  Snacks और music

### 🪷 तिलक / रोका

**कब:** Engagement / पहले

**जरूरी सामान:**

- [ ]  तिलक की थाली (रोली, चावल, मिठाई)
- [ ]  Shagun का लिफाफा
- [ ]  कपड़े (dulha ke liye)

### 🔥 फेरे (Saat Pheras)

**कब:** शादी के दिन

**पंडित जी का काम:** मंत्र, अग्नि स्थापना, फेरे, सिंदूर

**जरूरी सामान:**

- [ ]  हवन सामग्री (पंडित जी की list से)
- [ ]  लकड़ी / कंडे
- [ ]  घी, तेल
- [ ]  Mangalsutra
- [ ]  Sindoor
- [ ]  Kanyadaan के लिए पानी का कलश
- [ ]  Supari, paan, naariyal
- [ ]  Shagun ki thali

### 👋 विदाई (Vidai)

**कब:** फेरों के बाद

**जरूरी सामान:**

- [ ]  Dulhan की दोलची / Doli
- [ ]  Chawal (dulhan throws behind)
- [ ]  Photographer alert करें
- [ ]  Dulhan के लिए tissue / handkerchief

## ⚠️ Important Tips & SOP Rules

> **1. हर vendor से written agreement लें** — amount, date, time, cancellation policy
> 

> **2. Advance payment receipt रखें** — हर payment का screenshot या slip
> 

> **3. Emergency fund रखें** — कम से कम ₹30,000 अलग से
> 

> **4. एक family coordinator बनाएं** — जो शादी के दिन सब manage करे
> 

> **5. Photographer को shot list दें** — important moments miss न हों
> 

> **6. Catering के लिए 10-15% extra count करें** — last minute guests आते हैं
> 

> **7. Vendors को 1 दिन पहले reminder call करें**
> 

> **8. Vidai का dry run नहीं होता — Photographer को brief करें**
>
