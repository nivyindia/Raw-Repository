# 🏛️ Phase 1 — New Master Structure Design

> This page defines the target architecture — how the workspace SHOULD be structured once we’re done. We are not changing teamspaces (they stay as they are), but we are adding a consistent internal structure to each one and creating a global navigation layer.
> 

---

## 🏛️ The New Architecture (3 Layers)

> 📍 **Where you are:** Knowledge Base Restructuring Plan → Phase 1 | Completed: April 2026
> 

### Layer 1 — Global Entry Point (new)

A single page called **”🏠 Start Here — Welcome to Nivy”** will be created at the workspace root level. This is the first page any new team member reads. It will contain:

- What is Nivy? (brief company description)
- What are the different divisions/companies?
- A map of all teamspaces with one-line descriptions
- Links to the most important pages in each area
- A glossary of internal terms

### Layer 2 — Teamspace Home Pages (improved)

Every teamspace will have a proper home page with:

- A "What is this teamspace?" callout at the top
- A clear table of contents or navigation section
- Links to key sub-pages
- Owner and last-updated info

### Layer 3 — Page-Level Standards (added)

Every important page will have:

- A one-line description at the top explaining what the page is
- An emoji in the title for visual scanning
- A "Who should read this?" or "What is this?" note
- Consistent formatting

## 📁 Standard Internal Structure for Each Teamspace

Every active teamspace will follow this structure:

```
🏠 [Teamspace Name] — Home
├── 💡 What is [Teamspace]? (intro page)
├── 📍 Start Here (for newcomers)
├── 📂 [Section 1] (e.g., Strategy)
│   ├── Page 1
│   └── Page 2
├── 📂 [Section 2] (e.g., Operations)
│   ├── Page 1
│   └── Page 2
└── 📦 Archive (old or draft content)
```

---

## 📝 Page Naming Convention

All pages will follow this naming pattern:

**[Emoji] [Descriptive Name] — [Context if needed]**

Examples:

- ✅ `📊 Sales Overview — Nivy Global`
- ✅ `💰 GAAP Commission Structure`
- ✅ `💼 SOP: Onboarding New Team Members`
- ❌ `Sales Overview` (no context, no emoji)
- ❌ `DISCUSSED TOPICS & DECISIONS (LIST)` (shouting caps, hard to read)
