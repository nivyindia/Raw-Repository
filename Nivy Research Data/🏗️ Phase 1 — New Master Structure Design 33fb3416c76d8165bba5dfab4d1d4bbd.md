# 🏗️ Phase 1 — New Master Structure Design

> This section defines the ideal knowledge base structure for Nivy as an international company. Every teamspace, every section, and every page type is mapped out here.
> 

---

## 🌐 The Big Picture: How Nivy's KB Should Be Organised

Think of this like a building:

- **Floors = Teamspaces** (e.g., Nivy Global, Nivy Nexus, Nivy Next)
- **Rooms = Sections within each teamspace** (e.g., Strategy, Operations, Marketing)
- **Furniture = Individual pages** (e.g., a specific SOP, a specific report)

Currently the building has furniture dumped in hallways and some rooms built twice. We are moving everything to the right rooms.

---

## 🏗️ Proposed Master Teamspace Structure

Instead of 20 confusing teamspaces, we reorganise into **3 tiers**:

### 🔵 Tier 1 — Company-Wide (Shared across all divisions)

| Teamspace | What It Contains | Who Uses It |
| --- | --- | --- |
| **🏠 Nivy HQ** | Start Here, Company Overview, Org Chart, Mission/Vision, Announcements | Everyone |
| **🧠 Nivy OS (Operating System)** | Master databases, SOPs, Templates, Projects tracker | All teams |
| **💼 Business Plan** | Business Plan, Financial Plan, Market Analysis, Growth Strategy | Leadership |
| **💰 GAAP** | Accounting, Finance SOPs, Compliance | Finance team |

### 🟡 Tier 2 — Business Divisions (Each Nivy brand/entity)

| Teamspace | What It Contains | Who Uses It |
| --- | --- | --- |
| **🌐 Nivy Global** | Global expansion plans, Partner agreements, Franchising, Proposals | Business Dev |
| **🔗 Nivy Nexus** | Buyer-seller community, Outreach, UAE Markets, Social Media | Nexus team |
| **🚀 Nivy Next** | New initiatives, Setup checklists, Project overview | Innovation team |
| **🎓 Nivy Academy** | Training content, Courses, Learning paths | All staff |
| **🤝 Nivy Alliance** | Partnership docs, Alliance agreements | Partnerships |
| **❤️ Nivy Care Foundation** | CSR, Foundation work, Community initiatives | Foundation team |
| **💼 Nivy Advisory** | Advisory services, Brand guidelines, Client docs | Advisory team |
| **💼 Nivy Jobs** | Recruitment, Job descriptions, Hiring SOPs | HR team |

### 🟢 Tier 3 — Functional Departments (Inside Nivy OS or separate)

| Section | What It Contains |
| --- | --- |
| **📈 Growth Engine** | Content strategy, Social media, Campaigns, Competitor analysis |
| **📣 Marketing** | Marketing overview, Dashboards, Brand assets |
| **💵 Sales** | Sales overview, Pipelines, Scripts |
| **👥 HR** | HR overview, Policies, Onboarding |
| **💻 Technology** | Tech stack, Automation, Tools |
| **📊 Finance** | Finance overview, Budgets, Reports |
| **⚙️ Operations** | Operations plan, Logistics, Processes |

## 📄 Standard Page Structure (For Every Page)

Every page in the new knowledge base will follow this format:

```
📌 [Icon] [Clear Title — no abbreviations]

> 💡 What is this page? (1-2 sentences explaining purpose for new joiners)

💬 Last Updated: [date] | Owner: [name/team] | Status: [Draft/Active/Archived]

---

## [Section 1]
[Content]

## [Section 2]
[Content]

---
🔗 Related Pages: [links to connected pages]
```

## 🏷️ Status Tags (Every Page Gets One)

| Tag | Meaning |
| --- | --- |
| 🟢 Live | Active, current, being used |
| 🟡 Draft | Work in progress, not finalised |
| 🟠 Review Needed | Needs someone to check/update |
| 🔴 Outdated | Old version, kept for reference |
| 🖤 Archived | No longer active, kept for history |
| 📌 Template | Reusable blank format |

---

## 🔗 How Pages Link Together

Every page should have at minimum:

1. A **parent breadcrumb** (where does this belong?)
2. A **"Related Pages"** section at the bottom
3. A link back to its **department or division homepage**

This ensures a new joiner can always find their way around without needing someone to guide them.
