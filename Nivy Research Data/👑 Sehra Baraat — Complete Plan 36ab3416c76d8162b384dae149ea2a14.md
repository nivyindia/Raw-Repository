## 🛒 Saaman List

### Dulhe ki Tayaari

- [ ]  Sherwani (ironed, steam done)
- [ ]  Pagdi / Safa (pre-tied or tailor)
- [ ]  Sehra (phoolon ka — fresh)
- [ ]  Mojdi / Shoes
- [ ]  Accessories (brooch, kara, etc.)
- [ ]  Perfume
- [ ]  Dupatta / stole
- [ ]  Haircut done (2 din pehle)

### Sehra Ceremony (Ghar pe)

- [ ]  Sehra ready (fresh flowers)
- [ ]  Thali (tilak, diya, chawal, mithai)
- [ ]  Maa sehra pehnaaye
- [ ]  Photographer alert!

- [ ]  Thandaai / pani bottles
- [ ]  Mithai (baraatiyon ke liye)

## 📜 Baraat SOP — Step by Step

| Time | Kaam | Kaun |
| --- | --- | --- |
| Subah | Dulha tayaar hona shuru | Dulha + makeup/grooming |
| T-60 min | Sehra ceremony (ghar pe) | Maa + Photographer |
| T-45 min | Sab baraati ikkathe hote hain | Coordinator |
| T-30 min | Ghodi / car ready | Driver |
| T-15 min | Band shuru | Band team |
| T-0 | Baraat rowaana | Sab |
| Raste mein | Dance + masti | Baraati |
| Venue pahunchna | Band stop, Dulha utarta hai | Coordinator |
| Swagat | Dulhan side ka swagat | Dulhan side family |
| Tilak | Dulha ko tilak lagana | Designated vyakti |

> 💡 **Tip:** Band ko pehle se song list do. Aur ek vyakti ko specifically **traffic / route** ka dhyan rakhne ki zimmedaari do.
