# **PHASE 1: STRATEGY SETUP**

### **Objective**

Clearly define **who to target** on both sides (buyers + suppliers) so that all downstream work (research, outreach, qualification) is aligned and efficient.

---

## **Step 1: Confirm Niche & ICP (Buyer + Supplier)**

### **1.1 Inputs Required**

- Business vertical (e.g., cosmetics, construction, textiles, machinery) - PSC Flooring companies, wholesalers, retailer, manufacturers
- Geography (country, state, city if required) - uae
- Deal type (bulk orders, recurring supply, one-time procurement) - any
- Revenue goal per deal (minimum acceptable deal size) - 1000 aed

---

### **1.2 Buyer ICP Definition**

**Buyer ICP Fields to Finalize:**

| Category | Buyer ICP Factors |
| --- | --- |
| Industry | Exact industry + sub-industry |
| Buyer Type | Manufacturer / Distributor / Wholesaler / Retail Chain |
| Company Size | Small / Mid / Large (employee or revenue based) |
| Purchase Volume | MOQ / Monthly or quarterly volume |
| Buying Trigger | Expansion, cost reduction, new supplier, shortage |
| Geography | Country / region served |
| Decision Maker | Owner / Purchase Head / Procurement Manager |
| Contact Channels | Email / WhatsApp / LinkedIn |
| Budget Range | Estimated buying capacity |
| Payment Behavior | Advance / Partial / Credit |
| Compliance Needs | VAT, import/export, certifications |

**Output of Buyer ICP**

- 1–2 clear buyer personas (not more)
- Written ICP summary (1 paragraph)

---

### **1.3 Supplier ICP Definition**

**Supplier ICP Fields to Finalize:**

| Category | Supplier ICP Factors |
| --- | --- |
| Industry | Same or compatible with buyer niche |
| Supplier Type | Manufacturer / Trader / OEM |
| Production Capacity | Monthly output |
| MOQ | Minimum order quantity |
| Pricing Level | Low / Medium /  |
| Certifications | ISO, VAT, export licenses, |
| Geography | Manufacturing location |
| Experience | Years in business |
| Export Readiness | Domestic / Export capable |
| Payment Terms | Advance / LC / Credit |
| Logistics Capability | Local / National / International |

**Output of Supplier ICP**

- 1–2 supplier personas
- Clear inclusion + exclusion criteria

---

### **1.4 Final Phase-1 Deliverables**

✔ Buyer ICP document

✔ Supplier ICP document

✔ Approved niche & geography

✔ Green signal to start lead research

# **PHASE 2: LEAD RESEARCH**

### **Objective**

Build **clean, segmented, decision-maker level lead lists** for buyers and suppliers that are outreach-ready.

---

## **Step 2: Research Buyer Leads**

### **2.1 Buyer Lead Sources**

- Google Maps
- Industry directories
- Trade portals (IndiaMART, TradeIndia, Alibaba, etc.)
- Company websites
- LinkedIn Sales Navigator
- Chamber of Commerce listings
- Export/import databases (if applicable)

---

### **2.2 Buyer Lead Data to Capture**

| Field | Mandatory |
| --- | --- |
| Company Name | ✅ |
| Website | ✅ |
| Industry | ✅ |
| Buyer Type | ✅ |
| Contact Person Name | ✅ |
| Designation | ✅ |
| Email ID | ✅ |
| Phone / WhatsApp | Preferred |
| Location | ✅ |
| Estimated Purchase Volume | Optional |
| Notes | Optional |

**Quality Rules**

- Avoid info@ / sales@ unless no alternative
- Prefer decision-maker emails
- Validate domain exists

---

## **Step 3: Research Supplier Leads**

### **3.1 Supplier Lead Sources**

- Manufacturing clusters
- Trade fairs & exhibitor lists
- B2B portals
- Export councils
- Google search operators
- LinkedIn company search

---

### **3.2 Supplier Lead Data to Capture**

| Field | Mandatory |
| --- | --- |
| Company Name | ✅ |
| Manufacturing Location | ✅ |
| Product Category | ✅ |
| Capacity (if available) | Preferred |
| MOQ | Preferred |
| Certifications | Preferred |
| Contact Person | ✅ |
| Email | ✅ |
| Phone / WhatsApp | Preferred |
| Export Capability | Yes / No |
| Notes | Optional |

**Quality Rules**

- Must be active suppliers (not brokers unless allowed)
- Website or portal presence mandatory
- Avoid incomplete listings

---

## **Step 4: Build Segmented Lead Lists**

### **4.1 Segmentation Rules**

Create **separate lists** for:

- Buyers
- Suppliers

Each list further segmented by:

- Geography
- Sub-industry
- Deal size (if possible)

---

### **4.2 File Structure**

- Google Sheet / CRM
- Separate tabs:
    - Buyers – Raw
    - Suppliers – Raw
    - Buyers – Cleaned
    - Suppliers – Cleaned

---

### **4.3 Minimum Quantity Benchmarks**

- Buyers: **100–300 leads per niche**
- Suppliers: **50–150 leads per niche**

---

### **Final Phase-2 Deliverables**

✔ Buyer lead list (cleaned & segmented)

✔ Supplier lead list (cleaned & segmented)

✔ Ready for outreach batching
