# SMM Dept Hierarchy

### Hierarchy Overview (Top → Bottom)

| Level | Role | Core Responsibility | Typical Reports To |
| --- | --- | --- | --- |
| 1️⃣ | **Head of Marketing / Chief Marketing Officer (CMO)** | Owns overall marketing strategy, budget, KPIs, and brand voice. | CEO / Managing Director |
| 2️⃣ | **Social Media Marketing Director / Manager** | Leads social media strategy, sets goals, manages team & budget. | Head of Marketing / CMO |
| 3️⃣ | **Social Media Strategist / Planner** | Designs campaigns, selects channels, defines posting calendar. | Social Media Manager |
| 4️⃣ | **Content Manager / Creative Lead** | Oversees content creation — copy, visuals, videos, trends. | Social Media Manager |
| 5️⃣ | **Platform-Specific Specialists** | Execute content & engagement per platform. Examples below: | Content Manager / Strategist |
|  | • Instagram Specialist | Handles reels, stories, influencer collabs. |  |
|  | • LinkedIn Specialist | Handles B2B posting, brand authority. |  |
|  | • YouTube Manager | Handles video uploads, SEO, thumbnails. |  |
|  | • Twitter (X) Specialist | Handles news, engagement, quick response. |  |
| 6️⃣ | **Content Creators / Designers** | Graphic design, video editing, reels production, copywriting. | Content Manager |
| 7️⃣ | **Community Manager** | Replies to comments/DMs, handles followers, monitors sentiment. | Social Media Strategist |
| 8️⃣ | **Paid Ads Specialist / Performance Marketer** | Manages Meta, LinkedIn, and Google Ads campaigns. | Social Media Manager / CMO |
| 9️⃣ | **Analytics & Reporting Executive** | Tracks KPIs, prepares dashboards (engagement, CTR, ROI). | Social Media Manager |
| 🔟 | **Interns / Assistants** | Support scheduling, research, and coordination tasks. | Any senior team member |

## 🧩 Functional Sub-Teams inside the Department

| Sub-Team | Key Roles | Focus Area |
| --- | --- | --- |
| **Strategy & Planning** | Social Media Manager, Strategist | Market research, audience segmentation, tone of voice, calendar planning |
| **Creative & Content** | Content Manager, Designers, Video Editors, Copywriters | Visuals, videos, graphics, posts, captions |
| **Performance Marketing** | Paid Ads Specialist, Analytics Executive | Campaign optimization, budget allocation, conversion tracking |
| **Community & Engagement** | Community Manager, Platform Specialists | Commenting, responding, influencer relationships |
| **Data & Insights** | Analyst, Reporting Executive | Dashboard tracking, A/B testing, monthly reports |
