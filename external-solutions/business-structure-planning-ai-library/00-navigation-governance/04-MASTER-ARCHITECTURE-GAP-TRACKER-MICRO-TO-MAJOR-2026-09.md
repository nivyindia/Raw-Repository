## Completion rule

A gap is not complete merely because a concept exists in a catalog. It reaches **📚 Cataloged** only when the relevant reusable solution space is mapped. It reaches **🧪 Qualification** only after reproducible runtime/license/security/dependency checks. It reaches **🔧 Adapt/Integrate** only when an Nivy-compatible implementation path exists. It reaches **✅ Implemented** only after actual Nivy integration and verification.
