## 10. AI-native company layer

The target architecture should not simply have "one AI assistant." It should have reusable specialist capabilities:

```text
Company Context
      ↓
Strategy / Executive Layer
      ↓
Department Skills
      ↓
Specialist Skills / Agents
      ↓
Prompts + Templates + Knowledge
      ↓
Tools / APIs / Automation
      ↓
Human Review / Governance
      ↓
Outputs + Metrics + Learning
```

This is the key reuse opportunity: **adopt existing skills and frameworks as modules, then integrate only the missing orchestration and company-specific context.**
