# Sales Micro-Level Completeness Audit — International Sales

**Status:** v1.0 — 2026-09-16  
**Purpose:** Expand the Sales Department from stage-level coverage into atomic operational activities, controls, handoffs, evidence, and automation opportunities. This is a completeness checklist, not a claim that every listed capability already has a selected tool.

## Research principle

Use **REUSE → ADAPT → INTEGRATE → BUILD ONLY WHAT IS MISSING**.

Recent 2026 sales-process references reinforce that prospect research, preparation, qualification, needs assessment, proposal, negotiation, closing and follow-up are themselves collections of activities rather than single steps. Meeting workflows can contain preparation, research, agenda, structured capture, follow-up and CRM updates; discovery should capture context, pain, impact, stakeholders, budget, timeline and buying process. citeturn0search0turn0search2turn0search12

## 29. Atomic sales record / evidence model

Every meaningful sales event should be representable as:

`Account → Contact → Stakeholder → Interaction → Requirement → Pain → Goal → Evidence → Opportunity → Solution → Proposal → Commercial → Decision → Contract → Handoff → Outcome`

Every event should support:

`timestamp + owner + source + confidence + status + next action + due date + evidence + system-of-record ID`

## 30. Completeness conclusion

The previous files covered the Sales Department at operating-model and workflow levels. This file adds the **atomic operational layer** so that “meeting”, “proposal”, “prospecting”, “discovery”, “follow-up”, “promotion”, etc. are not treated as single black boxes.

The next research pass should search resources against these atomic capabilities. A capability is not considered a build gap merely because no single product performs the whole capability; composition through existing CRM, workflow, agent, skill, MCP/API, document and calendar components is preferred.
