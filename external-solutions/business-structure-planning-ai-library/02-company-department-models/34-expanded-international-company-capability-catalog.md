# Expanded International Company Capability Catalog

**Purpose:** Expand the reuse/discovery scope beyond departmental AI agents into the complete set of capabilities an international digital-services company may use.

**Principle:** DISCOVER → EVALUATE → REUSE → ADAPT → INTEGRATE → BUILD ONLY WHAT IS MISSING.

This is a discovery taxonomy, not a claim that every capability must be implemented. Each item should be researched for existing software, AI agents, skills, prompts, workflows, templates, APIs, MCP/connectors, open-source projects and commercial systems before custom development.

## Discovery rule
Do not stop at software discovery. A company capability may already exist as a prompt, skill, workflow, template, SOP, plugin, MCP server, GitHub repository, API integration, automation recipe, or complete operating system.

## Evidence rule
For each discovered asset record:
- Name
- Asset type
- Capability
- Department
- Source URL
- Official repository/site
- License/access model
- Open-source/free/paid
- Dependencies
- Integrations
- Data sensitivity
- Human approval requirements
- Maintenance/activity
- Reuse/adaptation notes
- Nivy destination
- Test status
