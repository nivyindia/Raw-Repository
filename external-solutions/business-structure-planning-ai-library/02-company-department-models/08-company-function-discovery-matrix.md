# Company Function Discovery Matrix

Use this matrix to drive future internet-wide discovery. The objective is to find existing methods, templates, software, prompts, skills, agents and workflows before building anything custom.

| Function | Search for frameworks | Search for templates/processes | Search for AI reuse |
|---|---|---|---|
| Corporate strategy | strategic planning, operating model, business architecture | annual plan, strategic plan, business plan | strategy agents, research prompts |
| CEO / executive | governance, decision rights, management cadence | executive dashboard, decision log | executive copilot, decision agents |
| Business architecture | capability model, value chain | capability map, TOM canvas | capability-mapping agents |
| Marketing | marketing operating model, funnel, lifecycle | campaign process, content system | marketing agents, skills, prompts |
| Sales / RevOps | sales process, RevOps, pipeline management | sales playbook, qualification, forecasting | SDR agents, CRM agents, lead research |
| Customer success | customer lifecycle, service management | onboarding, QBR, renewal SOP | support/CS agents |
| Product | product operating model, discovery | roadmap, PRD, discovery templates | product agents/skills |
| Engineering / IT | SDLC, ITSM, DevOps | incident/change/release SOPs | coding/DevOps agents |
| Finance | FP&A, controllership, treasury | budgeting, close, cash-flow templates | finance agents |
| Accounting / tax | accounting processes, controls | close checklist, tax workflow | bookkeeping/accounting agents |
| HR / People | org design, workforce planning | hiring, onboarding, performance templates | recruiting/HR agents |
| Legal / compliance | compliance frameworks, risk management | policy, contract, compliance checklists | legal/compliance agents |
| Operations | BPM, process architecture, Lean | SOP, process map, capacity planning | operations agents |
| Procurement | source-to-pay, vendor management | procurement SOP, vendor scorecard | procurement agents |
| Quality | QMS, ISO, continuous improvement | audit, CAPA, quality checklist | QA agents |
| Security | security frameworks, governance | policies, incident response | security agents |
| Data / analytics | data governance, BI operating model | KPI tree, dashboard, data dictionary | analytics agents |
| PMO | portfolio management, project governance | project charter, RAID, status report | project-management agents |
| Knowledge management | KM frameworks, taxonomy | wiki, knowledge-base templates | research/knowledge agents |
| Automation | process automation, orchestration | workflow templates | n8n/Make/Zapier/MCP/agent workflows |
| International expansion | global operating model, market entry | country launch plan, localization | market research/expansion agents |
| Partnerships | partner lifecycle, channel model | partner program, scorecards | partner discovery/management agents |
| Pricing | pricing strategy, monetization | pricing model, packaging | pricing/research agents |
| Risk | enterprise risk, controls | risk register, BCP | risk/compliance agents |
| Corporate communications | communication operating model | comms plan, crisis plan | communications agents |

## Research rule

For every row search multiple asset types:

**framework → process → template → software → prompt → skill → agent → automation → end-to-end system**

Stop only when additional searches are producing mostly duplicates or low-quality results, and record the stopping reason in the tracker.
