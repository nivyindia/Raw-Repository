# Ideal International Company Capability Model

**Status:** v1.0 — 2026-09-16

## Purpose

This is the reference capability model used to test whether the Nivy reuse library is missing material work performed by a mature international company.

It is a **capability model**, not a recommendation that Nivy must implement every function immediately.

## Cross-functional controls

Every material enterprise process should be evaluated for:

- owner
- accountable executive
- process steps
- inputs/outputs
- system of record
- permissions
- segregation of duties
- approval thresholds
- evidence
- audit trail
- KPI/SLA/KRI
- exception handling
- data classification
- retention
- business continuity
- cost
- human escalation

## International dimensions

A company operating across countries may additionally need:

- entity/jurisdiction map
- local statutory calendars
- employment/local payroll rules
- VAT/GST/sales-tax handling
- transfer pricing
- data residency/privacy requirements
- local licenses and registrations
- banking/currency/FX
- immigration/global mobility
- localized customer communications
- country-specific procurement and supplier requirements
- cross-border contracts
- sanctions/AML/KYC where relevant

## Comparison rule

A capability is considered **covered** only when the library contains a credible reusable asset or composition path **and** an implementation destination.

A capability is **partial** when components exist but an end-to-end workflow, governance, integration or jurisdiction-specific layer is still missing.

A capability is a **gap** when no credible reusable path has yet been identified.

A capability is an **implementation gap** when the research exists but Nivy has not yet integrated/tested it.
