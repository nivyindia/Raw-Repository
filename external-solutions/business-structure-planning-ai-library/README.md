# Existing Business Structure, Planning & AI Asset Library

**Purpose:** A reusable research warehouse of existing prompts, AI skills, templates, frameworks, operating-model resources, SOP systems, business-planning assets, enterprise systems and governance components that can help design and operate an international company.

**Principle:** `DISCOVER → EVALUATE → REUSE → ADAPT → INTEGRATE → BUILD ONLY WHAT IS MISSING`

This folder is intentionally a **source/reference layer**. Do not treat any listed asset as automatically approved for production. Check license, maintenance, security, compatibility, permissions and business fit before adoption.

## Current scope

The library now covers the original international-company capability checklist plus cross-cutting enterprise layers: enterprise architecture, BPM/value streams, master data, IAM, AI governance/AgentOps, data governance/lineage, evaluation/testing, ITSM, business continuity/DR, vendor/license management, payments, document lifecycle, change management and performance/continuous improvement.

## Execution model

For every capability, search the full chain:

`Business Outcome → Capability → Value Stream → Process → System → Application → Agent Team → Agent → Plugin → Skill → Command → Prompt → Workflow → API/MCP/Connector → RPA → SOP → Playbook → Template → Checklist → Dataset → Evaluation → Dashboard → Governance → Human Approval`

Then:

`DISCOVER → LICENSE/CHECK ACCESS → INSPECT → TEST UNCHANGED → ADAPT → APPROVE → INTEGRATE → MONITOR`

## Research integrity

The catalog links to original sources instead of copying large third-party bodies of text. Search results and repositories are discovery evidence; they are not endorsements. Licenses, security posture, maintenance, dependencies and commercial terms must be checked again at the point of adoption.
