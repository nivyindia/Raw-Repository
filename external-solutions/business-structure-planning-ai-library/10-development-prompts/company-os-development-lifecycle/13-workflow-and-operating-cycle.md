# Prompt 13 — Define Repeatable Workflows

Convert repeated work into explicit workflows.

For each workflow define:
trigger → inputs → preconditions → planning → execution steps → tools → approvals → verification → outputs → evidence → failure/retry → escalation → completion → learning.

Required workflows:
- new project intake
- task execution
- research/reuse discovery
- implementation
- testing
- release
- audit
- improvement
- incident/failure recovery
- dependency upgrade
- architecture change
- knowledge/documentation update
- resume after interruption

Store each workflow in WORKFLOWS.md or dedicated workflow files and link it from the master plan.
