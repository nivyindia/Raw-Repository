# Prompt 04 — Build the Master Plan and Roadmap

Convert architecture into an executable dependency-aware plan.

Create:
- phases
- projects
- epics
- tasks
- milestones
- gates
- dependencies
- acceptance criteria
- risks
- evidence requirements
- estimated effort
- priority
- status
- owner/agent
- blocked-by
- next action

Plan from v0.1 upward. Each phase must produce a usable/verifiable increment.

Gate model:
G0 identity/scope
G1 reuse discovery
G2 architecture
G3 inputs/data contracts
G4 implementation
G5 tests
G6 security
G7 evidence
G8 integration
G9 release
G10 post-release audit

Never mark a gate complete from prose alone; require evidence.
