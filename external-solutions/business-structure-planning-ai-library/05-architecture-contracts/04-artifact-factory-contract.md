# Canonical Business Artifact Factory Contract

Input → Generate → Structured Spec → Validate → Deterministic Render → Review → Publish → Evidence

## Artifact examples
Documents, proposals, reports, presentations, social creatives, website pages, SOPs, plans, dashboards and other business outputs.

## Required controls
- Source-of-truth inputs
- Brand/policy context
- Structured intermediate representation
- Schema validation
- Deterministic rendering where practical
- Human review gate according to risk
- Version/provenance
- Publish authorization
- Output evidence
