# Canonical Skill Contract

Status: Draft for Nivy adaptation from Wave 4/5 research.

## Contract
Trigger/Intent → Preconditions → Instructions → References → Tools → Inputs → Execution → Outputs → Validation → Evaluation → Failure/Retry → Security → Version → Deprecation

## Required fields
- skill_id
- name
- purpose
- trigger
- inputs
- outputs
- tools
- permissions
- instructions
- references
- validation
- evaluation_cases
- failure_policy
- owner
- version
- lifecycle_state

## Rule
A skill is reusable only after provenance, license, security and evaluation status are recorded.
