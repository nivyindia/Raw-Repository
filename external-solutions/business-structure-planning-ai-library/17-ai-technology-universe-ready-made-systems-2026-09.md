## 30. Nivy reuse rule

For every item discovered:

**REUSE → ADAPT → INTEGRATE → REFERENCE → BUILD**

Record:

- canonical URL
- license
- current status
- self-hostability
- model support
- MCP/A2A
- memory
- RAG
- multimodal
- tools
- integrations
- security
- evaluation
- deployment
- Nivy capability/department
- verification date

Do not copy code merely because a repository is public/open-source. License and dependency compatibility must be verified before incorporation.
