## Adoption lifecycle

DISCOVERED → SOURCE-VERIFIED → LICENSE-CHECKED → SANDBOX TEST → HUMAN REVIEW → ADAPTED → INTEGRATED → PRODUCTION

No candidate should be marked Production merely because the repository is public or has a permissive license.

## Minimum test record

- Source URL
- Repository commit/version tested
- License and third-party notices
- Dependencies
- Required credentials
- Data touched
- Tools/actions available to the agent
- Human approval points
- Test cases
- Failure modes
- Security findings
- Cost
- Decision: adopt / adapt / monitor / reject
