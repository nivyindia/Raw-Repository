## Priority reuse candidates

1. **Process backbone:** APQC + ISO process approach.
2. **Operating-model backbone:** McKinsey operating-model concepts + Capstera templates.
3. **Company OS implementation reference:** Focus688 + Stratisian.
4. **AI skills layer:** astDeniss + itsual + AI Agents Library + Vexjoy.
5. **Automation layer:** n8n workflow library + selected reusable templates.
6. **Ready-made agent layer:** Agent Marketplace + Arahi + MarketInc; validate permissions, security, pricing and actual integration before adoption.
7. **SOP layer:** OpenAIToolsHub + Stratisian + existing Nivy SOP methodology.

## Evidence rule

A marketplace listing is evidence that a resource exists, **not** evidence that it is effective or production-ready. Before adoption, record: owner/publisher, last update, dependencies, permissions, license, pricing, security/privacy, integration fit, human-review points, and test result.
