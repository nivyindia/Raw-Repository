## Source-selection rule

Prefer:

1. official source repository or publisher;
2. documented license/access terms;
3. inspectable implementation;
4. active maintenance signal;
5. clear dependencies and permissions;
6. reproducible tests.

A source being popular does not by itself make it suitable for production adoption.

## Current evidence note

Anthropic's official repository states that its plugins combine skills, connectors, slash commands and sub-agents, and are intended to be customized for an organization's tools, terminology and processes. This makes the repository a particularly useful reference architecture for the Nivy reuse program.

The Small Business plugin explicitly warns that outputs are not financial, tax, legal or HR advice and should receive appropriate review. Nivy should preserve the same approval principle in any adapted workflow.
