## Qualification fields required before reuse

Capability → exact asset → source URL → repository → license → current status → maintenance → dependencies → runtime → inputs → outputs → tools → permissions → security → cost → deployment → test evidence → adaptation required → Nivy destination → qualification status.

## Research note

The ecosystem is much larger than a normal hand-curated list. A 2026 research dataset reported 3,797,117 SKILL.md occurrences across 282,200 public repositories, showing that discovery must be treated as an ongoing search/indexing problem rather than a one-time catalog. Use this catalog as the high-value starting set, then mine broader repositories and registries systematically.
