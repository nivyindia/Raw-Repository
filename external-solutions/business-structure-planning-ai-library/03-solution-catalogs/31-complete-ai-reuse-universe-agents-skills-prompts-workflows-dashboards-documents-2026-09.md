# Complete AI Reuse Universe — Agents, Generative AI, Skills, Prompts, Workflows, Dashboards, Reporting, Documents & Company Automation — September 2026

## Purpose

This is the **broad reusable-resource index** for the Business Structure Planning & AI Reuse Library.

It deliberately goes beyond "AI agents". The discovery target is:

**MODEL → AGENT → MULTI-AGENT → SKILL → PROMPT → MCP/TOOL → CONNECTOR → WORKFLOW → AUTOMATION → SOP → TEMPLATE → DOCUMENT → DASHBOARD → REPORT → DEPARTMENT SYSTEM → COMPANY SYSTEM**

Governing rule:

**DISCOVER → DECOMPOSE → REUSE → ADAPT → INTEGRATE → BUILD ONLY WHAT IS MISSING**

This catalog is a discovery index, not a production approval list. Every candidate must still be checked for current maintenance, license, security, privacy, API limits, cost, regional availability and runtime behavior.

# 32. Reuse decision model

**DO NOT BUILD** if a maintained resource already covers the requirement adequately.

**ADAPT** when the resource covers most of the requirement but needs Nivy integration.

**COMPOSE** when several small resources together cover the requirement.

**WRAP** when an external resource needs a Nivy adapter/MCP/API boundary.

**BUILD** only for a genuine integration/domain gap.

**REJECT** when license, security, quality, maintenance or architectural fit is unacceptable.
