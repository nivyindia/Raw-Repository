**Reuse rule:** DISCOVER → DECOMPOSE → REUSE → ADAPT → INTEGRATE → BUILD ONLY WHAT IS MISSING.

## 9. Voice command → Nivy Company OS

Target experience:

- “Jarvis, what happened to sales yesterday?” → authenticate user → understand role → query CRM/ERP/analytics → summarize → speak answer.
- “Jarvis, research our top five competitors and prepare a report.” → research → evidence → competitor matrix → report → knowledge base → notify.
- “Jarvis, prepare this week's YouTube content.” → channel strategy → trends → competitor analysis → topics → scripts → production queue → approval.
- “Jarvis, show me which department is missing its KPIs.” → RBAC → company KPI graph → department aggregation → exceptions → executive dashboard/voice summary.
- “Jarvis, publish this campaign.” → validate → rights/policy checks → approval → publish through connector → audit log.

## 11. Build-vs-reuse priority

Prioritize reuse for wake-word/STT/TTS, computer-use, MCP discovery, research/reporting, YouTube production, video assembly, avatar/lip-sync, social content, SEO/marketing pipelines, BI dashboards and department operating models.

Build the Nivy-specific integration, company graph, identity/RBAC, unified UI, approval policy, memory/context layer and cross-department orchestration where existing systems do not provide the required integration.
