# Ideal International Company vs Nivy Reuse Coverage Matrix

**Status:** v1.0 — 2026-09-16

## Purpose

This is the scope-control matrix used to prevent both under-building and endless research expansion.

### Status meanings

- **Covered** — capability is represented by existing discovery/reuse material.
- **Partial** — capability exists but depth, integration or implementation assets are incomplete.
- **Gap** — no sufficiently developed reusable path is currently represented.
- **Implementation gap** — architecture is known, but production implementation is still missing.

## Decision

The library is **not literally complete for every possible enterprise specialization**, because new software and methods continuously appear. However, this audit identifies the remaining material capability families that are worth targeted discovery before implementation is considered scope-complete.

After the listed gaps receive a targeted discovery pass, the default should be:

`VERIFY → TEST → SELECT → ADAPT → INTEGRATE → PILOT`

rather than continuing to expand the generic company-function list.
