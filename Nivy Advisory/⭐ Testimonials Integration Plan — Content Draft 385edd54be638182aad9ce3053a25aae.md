## Objective

Integrate testimonials across Home, Service pages, and Country pages per Phase 2 plan, reinforcing the Trust & Proof Strategy (Part 1.8).

## Placement Plan

| Page | Placement | Selection Logic |
| --- | --- | --- |
| Home | Dedicated testimonial carousel, Section 7 (placeholder already reserved in Home draft) | 2–3 strongest, mixed across regions/services |
| Each Service page | Single testimonial block near bottom, above final CTA | Client who used that specific service |
| Each Country page | Single testimonial block in Local Trust Signals section | Client based in or filing in that country — "a UAE prospect trusts a UAE case study more than a US one" (Part 5.5) |
| Case Studies page | Quote already embedded per case (Context→Challenge→Solution→Result→Quote framework) | One per hub cluster |

---

## Collection Process (to execute before this can go live)

1. Identify 6–10 happy clients across different countries/services/tiers.
2. Send permission + quote request (short form: 2–3 sentences + permission to use name/company/photo or anonymize).
3. Tag each testimonial by: country, service used, package tier.
4. Store in a simple testimonials database (Name/Company, Quote, Country, Service, Tier, Permission status, Photo).
5. Map into the placement plan above once collected.

---

## Format Standard

- Keep quotes under 40 words for carousel/card use.
- Always pair with name + role + company (or "Name, [Country] e-commerce founder" if anonymized).
- Never fabricate or use composite/placeholder testimonials on the live site — unlike case studies, testimonials must be 100% real and permissioned.
