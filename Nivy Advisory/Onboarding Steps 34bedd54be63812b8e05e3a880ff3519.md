# Onboarding Steps

> The complete step-by-step process for onboarding a new client. Follow this every time — no exceptions.
> 

---

## Standard Onboarding Timeline: 5 Business Days

### Day 1 — Agreement & Welcome

- [ ]  Send and collect signed Service Agreement
- [ ]  Send Welcome Email with onboarding instructions
- [ ]  Introduce client to their dedicated Account Manager
- [ ]  Share the Onboarding Form link

### Day 2 — Information Gathering

- [ ]  Receive completed Onboarding Form
- [ ]  Collect all documents from the Document Checklist
- [ ]  Request read-only bank feed access (or document uploads)
- [ ]  Confirm software / tools the client is currently using

### Day 3 — System Setup

- [ ]  Set up client profile in internal accounting software
- [ ]  Connect bank feeds and import historical transactions
- [ ]  Create chart of accounts tailored to client's business
- [ ]  Set up client folder in document portal

### Day 4 — Initial Review

- [ ]  Review prior month's records if transferring from another accountant
- [ ]  Identify any catch-up bookkeeping required
- [ ]  Flag any compliance issues or overdue filings
- [ ]  Prepare scope summary for kick-off call

### Day 5 — Kick-off Call

- [ ]  30-minute onboarding call with client and Account Manager
- [ ]  Walk through what we'll do, when, and how we'll communicate
- [ ]  Confirm reporting preferences (format, frequency, channel)
- [ ]  Set expectations for first deliverable date
