# Document Checklist

> All documents required from a new client before work can begin. Share this checklist as part of the Day 1 onboarding process.
> 

---

## All Clients

- [ ]  Government-issued ID (passport or driver's license)
- [ ]  EIN confirmation letter (CP 575 or 147C)
- [ ]  Prior year tax returns (last 2 years)
- [ ]  Bank statements (last 3 months, all accounts)
- [ ]  Credit card statements (last 3 months, all cards)
- [ ]  Existing accounting file export (QuickBooks / Xero backup, if applicable)

---

## If Incorporated (LLC, S-Corp, C-Corp, Partnership)

- [ ]  Articles of Incorporation / Organization
- [ ]  Operating Agreement or Bylaws
- [ ]  List of shareholders / members with ownership percentages
- [ ]  Any existing equity or shareholder loan agreements

---

## If Payroll Service Required

- [ ]  List of all employees (name, address, SSN, start date, pay rate)
- [ ]  W-4 forms for each employee
- [ ]  State payroll account numbers (if already registered)
- [ ]  Payroll history for the current year (if mid-year start)

---

## If Tax Filing Required (US)

- [ ]  Prior year tax returns (as above)
- [ ]  All 1099s and W-2s received
- [ ]  Record of estimated tax payments made
- [ ]  Any IRS or state notices received
- [ ]  Business asset list (for depreciation schedules)

---

## Secure Document Submission

All documents should be submitted via the secure client portal. Do not send sensitive documents via email without encryption.
