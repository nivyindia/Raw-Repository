# Package Recommendation Logic

> Use this guide to match every prospect to the right package. Never guess — always qualify first (see: Qualification Questions), then apply this logic.
> 

---

## Decision Tree

### Step 1: Monthly Transaction Volume

- **< 100 transactions/month** → Lean toward **Starter**
- **100–500 transactions/month** → Lean toward **Growth**
- **500+ transactions/month** → Lean toward **Scale**

### Step 2: Tax Complexity

- **Single state, simple filing** → No upgrade needed
- **Multi-state or international** → Add Tax Support Package
- **GST / VAT / IRS issues** → Add Tax Support Package

### Step 3: Team / Payroll

- **Solo / no employees** → No payroll add-on needed
- **1–10 employees** → Add Payroll Management Package
- **10+ employees** → Scale Package + Payroll

### Step 4: Advisory Need

- **Stable business, just needs compliance** → No CFO upgrade
- **Growing, needs budgets + forecasts + investor reporting** → Add Fractional CFO Package
- **Series A+ or major growth phase** → Scale + CFO (full)

| Prospect Type | Recommended Package |
