# Plan & Task Tracker

This is the compact control ledger. Detailed plans remain in their original files.

## State Definitions
- `NOT STARTED` — identified but not begun
- `IN PROGRESS` — actively being implemented
- `BLOCKED` — dependency/approval/permission prevents progress
- `READY TO VERIFY` — implementation exists; verification pending
- `DONE` — implementation + verification + evidence recorded
- `DEFERRED` — intentionally postponed with reason
