# Promotion Rules

## Decision Tree

```text
Research item
   ↓
Existing canonical solution?
   ├─ YES → link/reference → do not duplicate
   │
   └─ NO
       ↓
Reusable external solution?
       ├─ YES → adapt/integrate → transfer-ready
       │
       └─ NO
           ↓
Partial solution?
           ├─ YES → adapt + record missing pieces
           │
           └─ NO → GAP REGISTRY
                    ↓
                 build only what is missing
```

## Promotion Checklist

Before promotion:

- [ ] Source/provenance recorded
- [ ] Duplicate check completed
- [ ] Destination repository identified
- [ ] Destination path identified
- [ ] License/usage constraints checked where applicable
- [ ] Adaptation requirements documented
- [ ] Dependencies documented
- [ ] Validation evidence recorded
- [ ] No secrets copied
- [ ] Provenance link retained
- [ ] Promotion tracker updated

## No Silent Promotion

Promotion must be traceable. A destination artifact should be able to answer:

> "Which research item caused this to be added or adapted?"
