## Root cause (found while fixing, not just guessed)

Confirmed the audit's core finding — no `dashboard.md`, no generator script anywhere. But checking *why* it's missing surfaced a second, more specific gap: Doc 07 §9 promises a metrics table with 7 fields, and the workflows that already exist don't actually produce all 7:

| Doc 07 §9 field | Who computes it today |
|---|---|
| Total Documents | `health-report.yml` ✅ |
| Published | `health-report.yml` ✅ |
| Outdated (past Next Review) | `health-report.yml` ✅ |
| Unowned (no Owner set) | `health-report.yml` ✅ |
| Draft (stuck >30 days) | `health-report.yml` ✅ |
| Awaiting Review | ❌ nobody — no workflow checks for `Lifecycle Status: In Review` |
| Broken Internal Links | ❌ `check-links.yml` only **fails the build** with inline errors, it never outputs a count anywhere reusable |

So even if `health-report.yml`'s weekly Issue were rendered as a page instead of an Issue, 2 of the 7 promised numbers still wouldn't exist. And structurally, `health-report.yml`, `check-links.yml`, and `orphan-detection.yml` are three independent jobs posting to three different places (an Issue, build failures, another Issue) — nothing reads across all three into one view. That's the actual reason "central visual view" is missing: there's no single job with visibility into all three checks at once.

So the fix adds a 4th, consolidating workflow rather than trying to bolt a dashboard onto one of the three existing ones (which would tangle unrelated jobs together) — it re-runs the same lightweight checks the others do, fills in the 2 missing fields, and writes one committed file.

## The fix — add `Company-OS/.github/workflows/dashboard-generate.yml`

```yaml
name: Generate Documentation Health Dashboard

# Consolidates what health-report.yml, check-links.yml, and orphan-detection.yml
# already check into the single dashboard.md file Doc 07 §9 specifies, plus the
# 2 fields none of those three currently compute (Awaiting Review, Broken Links count).
# Runs after the other Monday jobs so their same-day Issues are settled first.

on:
  schedule:
    - cron: '0 6 * * 1'   # weekly, Monday 06:00 UTC (after the 03:00/04:00/05:00 jobs)
  workflow_dispatch: {}

jobs:
  build-dashboard:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      - name: Compute all 7 metrics
        run: |
          TOTAL=0; OUTDATED=0; AWAITING_REVIEW=0; UNOWNED=0; DRAFT_STUCK=0; PUBLISHED=0; BROKEN_LINKS=0
          TODAY=$(date +%Y-%m-%d)

          for file in $(find 01_AREAS 02_PROJECTS 03_RESOURCES -name "*.md" ! -name "README.md" ! -name "Glossary.md" ! -name "FAQ.md"); do
            TOTAL=$((TOTAL+1))
            status=$(grep -m1 "^Lifecycle Status:" "$file" | sed 's/Lifecycle Status:[[:space:]]*//')
            owner=$(grep -m1 "^Owner (Accountable):" "$file" | sed 's/Owner (Accountable):[[:space:]]*//')
            next_review=$(grep -m1 "^Next Review:" "$file" | sed 's/Next Review:[[:space:]]*//')

            [[ "$status" == "Published" ]] && PUBLISHED=$((PUBLISHED+1))
            [[ "$status" == "In Review" ]] && AWAITING_REVIEW=$((AWAITING_REVIEW+1))
            if [[ -z "$owner" || "$owner" == "Unassigned" || "$owner" == "[Role]"* ]]; then
              UNOWNED=$((UNOWNED+1))
            fi
            if [[ "$status" == "Draft" ]]; then
              last_mod=$(git log -1 --format=%ct -- "$file" 2>/dev/null || echo 0)
              age_days=$(( ($(date +%s) - last_mod) / 86400 ))
              [ "$age_days" -gt 30 ] && DRAFT_STUCK=$((DRAFT_STUCK+1))
            fi
            [[ -n "$next_review" && "$next_review" < "$TODAY" ]] && OUTDATED=$((OUTDATED+1))

            dir=$(dirname "$file")
            for link in $(grep -oE '\]\([^)]+\.md\)' "$file" | sed -E 's/\]\((.+)\)/\1/'); do
              [[ "$link" == http* ]] && continue
              target=$(realpath -m --relative-to=. "$dir/$link")
              [ ! -f "$target" ] && BROKEN_LINKS=$((BROKEN_LINKS+1))
            done
          done

          {
            echo "# Documentation Health Dashboard"
            echo ""
            echo "Home › 03_RESOURCES › Company_Master_Standards"
            echo ""
            echo "_Last updated: $TODAY (auto-generated weekly by \`dashboard-generate.yml\`, do not edit by hand)_"
            echo ""
            echo "| Metric | Count |"
            echo "|---|---|"
            echo "| Total Documents | $TOTAL |"
            echo "| Outdated (past Next Review date) | $OUTDATED |"
            echo "| Awaiting Review | $AWAITING_REVIEW |"
            echo "| Unowned (no Owner set) | $UNOWNED |"
            echo "| Draft (stuck >30 days) | $DRAFT_STUCK |"
            echo "| Published | $PUBLISHED |"
            echo "| Broken Internal Links | $BROKEN_LINKS |"
            echo ""
            echo "## Details"
            echo "- Full weekly breakdown (per-file lists): see the latest \`health-report\` labeled Issue."
            echo "- Orphan documents: see the latest \`orphan-report\` labeled Issue."
            echo "- Broken link locations: see the \`check-links.yml\` run logs for the exact file/line."
          } > 03_RESOURCES/Company_Master_Standards/dashboard.md

      - name: Commit updated dashboard
        run: |
          git config user.email "dashboard-bot@company-os.local"
          git config user.name "Dashboard Bot"
          git add 03_RESOURCES/Company_Master_Standards/dashboard.md
          git commit -m "Update documentation health dashboard" || echo "No changes"
          git push
```
