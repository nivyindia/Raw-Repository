# Projects

Home › 02_PROJECTS

## Purpose
Time-bound, cross-department work lives here (PARA: Projects) — anything with a defined
end date and deliverable, involving more than one department. Ongoing, non-time-bound
department work stays in `01_AREAS/[DEPT]/` instead — if it never "finishes," it's an Area,
not a Project.

## Starting a New Project
1. Copy the `_TEMPLATE — Project Name Year/` folder in this directory.
2. Rename it to your actual project, following the pattern `[Project Name — Year]/`
   (e.g. `Website Redesign 2026/`).
3. Keep the three sub-folders as-is: `Charter & Plan/`, `Working Docs/`, `Final Deliverables/`.
4. Name files per the standard formula (GOVERNANCE/04-Classification-Naming-Rulebook.md):
   `PROJ-DOC-[ShortCode] — Title.md`

**Example:** `02_PROJECTS / Website Redesign 2026 / Charter & Plan / PROJ-DOC-Website2026 — Project Plan.md`

## When a Project Finishes
Move the whole project folder to `04_ARCHIVE/PROJECTS/`, mirroring this path
(GOVERNANCE/03-Folder-Structure-Map.md, Rule 3 — nothing is ever deleted, only archived).
