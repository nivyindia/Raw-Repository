# 👋 Welcome to [Company Name]

This is your Company OS — every policy, SOP, workflow, report, and piece of company knowledge lives here, organized so you never have to guess where something is.

## Your first steps

1. **Read this page fully** — it explains how the whole system works.
2. **Read the Company Overview** → `03_RESOURCES/Company_Master_Standards/Company-Overview.md`
3. **Go to your Department's home page** → see the table on the main [README](../README.md)
4. **Read the Company-wide Glossary** → `03_RESOURCES/Company_Master_Standards/Glossary.md`
5. **Follow your Department's "Start Learning" link** on its README

## How this repository is organized

```
01_AREAS/        → every department, same internal structure every time
02_PROJECTS/      → time-bound, cross-department projects
03_RESOURCES/      → shared templates, company-wide policies, governance rules, glossary
04_ARCHIVE/          → retired content (never deleted, just moved here)
```

## How to find anything — 3 ways

- **Browse:** Company → Department → Topic (via the folders above)
- **Role Path:** Your Department's README → "Start Learning" → your role's guided sequence
- **Search:** use GitHub search, or ask the Company OS AI Assistant

## The one rule to remember

> *An AI answer is not official. The Published document in this repository is official.*
