8. n8n के लिए एक बहुत जरूरी Skill

मैं इसे mandatory रखूंगा:

n8n Agent Development Skill

इसके अलावा यह community skill भी useful है:

n8n AI Agent Workflow Pattern

इसमें standard architecture:

Trigger
   ↓
AI Agent
   ├── Model
   ├── Tools
   ├── Memory
   └── Output Parser
   ↓
Process
   ↓
Output

के साथ tool selection, $fromAI, structured output, memory/session ID, HITL और RAG जैसे patterns cover होते हैं।
