# Nivy Autonomous Start / Continue Command

## Activation

> **START / CONTINUE this repository.** Read the canonical repository state, README (if present), implementation plans, progress trackers, governance rules, and existing work before acting. Inspect the current repository state. Identify the highest-priority incomplete and unclaimed task that actually belongs to this repository. Claim it before substantive work, mark it `IN_PROGRESS`, execute the work, verify it, record evidence and status, commit the completed work, release the claim, re-check repository state, and automatically continue to the next highest-priority unclaimed task. Do not start from scratch. Do not duplicate existing work. Respect this repository's purpose, provenance, licensing, authority boundaries, validation, and human-approval requirements. If this is a source/reference warehouse, preserve source material and do not invent implementation work. Continue until all currently actionable work is complete or a genuine blocker requires human input.

## Canonical Loop

`CHECK → READ CANONICAL STATE → INSPECT → FIND HIGHEST-PRIORITY UNCLAIMED TASK → CLAIM → MARK_IN_PROGRESS → WORK → VERIFY → RECORD EVIDENCE + STATUS → COMMIT → RELEASE CLAIM → RECHECK → CONTINUE`
