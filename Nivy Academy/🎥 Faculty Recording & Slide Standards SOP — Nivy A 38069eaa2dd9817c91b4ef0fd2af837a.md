> **Rule:** Every recording made for Nivy Academy must follow these standards before it is uploaded to the LMS. Non-compliant recordings will be returned for re-recording.

# Part 1 — Before You Record

## 1.1 Preparation Checklist

- [ ]  Script or detailed outline is complete and reviewed
- [ ]  Slides are finalised (see Part 2 for slide standards)
- [ ]  All tools/demos you will show are logged in and loaded in the browser
- [ ]  Practice run completed (at least once, audio checked)
- [ ]  Notification banners and phone are OFF
- [ ]  "Do Not Disturb" is enabled on OS
- [ ]  Recording software is tested (OBS / Loom / Zoom — all acceptable)

---

## 1.2 Technical Setup — Camera

| Setting | Standard |
| --- | --- |
| **Resolution** | Minimum 1080p (1920×1080). 4K preferred if camera supports it. |
| **Camera angle** | Eye-level. Camera should be at or just above eye level — not below (no "looking down" angle). |
| **Framing** | Head + shoulders in frame. Leave a small gap above the head. |
| **Background** | Solid colour wall (white, grey, or dark preferred) OR a clean virtual background (Nivy branded or plain). No clutter. |
| **Webcam minimum** | Logitech C920 or equivalent. Built-in laptop cameras acceptable only if 1080p confirmed. |

---

## 1.3 Technical Setup — Audio

| Setting | Standard |
| --- | --- |
| **Microphone** | External mic required (USB or 3.5mm). Built-in laptop mic is not permitted. Minimum: BounceDeck, HyperX SoloCast, or equivalent. |
| **Audio check** | Record 30 seconds and listen back before starting. Check for hiss, echo, background noise. |
| **Room treatment** | Record in a small room with soft furnishings (bedroom, carpeted room). Avoid bare-walled echo-prone rooms. |
| **Level** | Voice should peak at -6dB to -3dB. Not clipping, not too quiet. |
| **No music** | No background music during lecture recordings. |

---

## 1.4 Technical Setup — Lighting

| Setting | Standard |
| --- | --- |
| **Primary light** | Soft front light (ring light or softbox) facing your face. No harsh overhead lighting. |
| **No backlighting** | Never record with a window directly behind you — face appears dark. |
| **Minimum** | A ₹1,500 ring light is sufficient. Natural window light from the side is acceptable if consistent. |

---

## 1.5 Screen Recording Settings (for tool walkthroughs)

| Setting | Standard |
| --- | --- |
| **Resolution** | 1920×1080 minimum |
| **Frame rate** | 30 fps minimum |
| **Browser** | Chrome only (consistent look). Hide bookmarks bar. Remove personal bookmarks visible to camera. |
| **Zoom** | Browser zoom at 100% unless specifically zooming in for emphasis |
| **Tabs** | Only the tabs you need. Close all others before recording. |
| **Cursor** | Use "Cursor Highlight" or "Click indicator" plugin so viewers can see where you click |

# Part 2 — Slide Design Standards

## 2.1 Branding

| Element | Standard |
| --- | --- |
| **Fonts** | Headings: **Poppins Bold** / Body: **Inter Regular** or **DM Sans**. Google Fonts, free. |
| **Primary colours** | Nivy Navy: `#1A2B4A` / Nivy Gold: `#E8A020` / White: `#FFFFFF` / Light Grey: `#F5F5F5` |
| **Logo** | Nivy Academy logo must appear on slide 1 (title) and slide (last). Not required on every slide. |
| **Slide size** | 16:9 widescreen (1920×1080 px in Canva, or "Widescreen" in PowerPoint/Google Slides) |

---

## 2.2 Layout Rules

| Rule | Do ✅ | Don’t ❌ |
| --- | --- | --- |
| Text density | Max 6 lines per slide | Wall-of-text slides |
| Font size | Body: min 24pt. Heading: min 36pt | Tiny text (under 20pt) |
| Images | High-res, royalty-free (Unsplash, Pexels, Freepik) | Blurry, pixelated, or watermarked images |
| Bullet points | Max 5 per slide. Use short phrases, not full sentences | 10-bullet slides |
| Colour contrast | WCAG AA minimum (test at [contrast checker](https://webaim.org/resources/contrastchecker/)) | Light grey text on white background |
| Animations | Subtle appear/fade only | Spinning, bouncing, complex animations |
| Emojis | Use sparingly for emphasis | Emojis as bullet substitutes |

---

## 2.3 Required Slides (Every Module)

| Slide # | Type | Content |
| --- | --- | --- |
| 1 | **Title Slide** | Module name, sub-topic, faculty name, Nivy Academy logo, date |
| 2 | **Learning Objectives** | 2–4 bullet objectives (what student will be able to DO) |
| *(middle)* | **Content slides** | Your teaching content |
| *(second to last)* | **Key Takeaways** | 3–5 bullet summary of what was covered |
| *(last)* | **Assignment / Next Step** | What the student does now. Links to checkpoint or practical task. |

---

## 2.4 Slide Export for LMS

- Export slides as PDF (for downloadable handout alongside video)
- Name file: `[PhaseID]_[SubTopicID]_[Title]_Slides.pdf` (e.g. `P1.1.3_NLP-Semantic-SEO_Slides.pdf`)
- Upload both the video AND the PDF to LMS together

# Part 3 — During Recording

| Practice | Standard |
| --- | --- |
| **Intro** | Start every recording: *"Hi, I’m [name], and in this module we’re going to cover [topic]. By the end you’ll be able to [1–2 objectives]."* |
| **Speaking pace** | Speak at 130–150 words per minute. Slower than normal conversation. Pause after key points. |
| **Mistakes** | If you make a mistake, pause for 3 seconds (easy to cut in editing), then redo the sentence. Do NOT restart the entire recording. |
| **Engagement** | Address the student directly: “You’ll notice…” “Try this on your own…” Not: “Students should…” |
| **Demo narration** | When doing live tool demos, narrate every click: “I’m now clicking on… and here you can see…” |
| **Outro** | End every recording: *"That wraps up [sub-topic]. Complete the checkpoint quiz below before moving on. See you in the next one!"* |

---

# Part 4 — After Recording — Editing Standards

| Element | Standard |
| --- | --- |
| **Intro/Outro** | Add Nivy Academy branded intro (3–5 sec) and outro (5 sec). Template in shared Drive. |
| **Chapter markers** | Add chapter markers for every major section (required for LMS and YouTube uploads) |
| **Lower thirds** | Display faculty name + title in lower-third on first appearance. White text on Nivy Navy background. |
| **Captions** | Auto-generate captions (Descript, Kapwing, or OBS). Review and correct before export. |
| **Noise reduction** | Apply light noise reduction if needed. Do not over-compress. |
| **Export settings** | MP4, H.264, 1080p, 30fps, audio: AAC 192kbps |
| **File naming** | `[PhaseID]_[SubTopicID]_[Title]_v1.mp4` (e.g. `P1.1.3_NLP-Semantic-SEO_v1.mp4`) |

# Part 5 — Upload Checklist (LMS)

Before marking any task as ✅ Done, confirm ALL of the following:

- [ ]  Video is uploaded and plays correctly in LMS

- [ ]  Checkpoint quiz is built and linked below the video
- [ ]  Captions are enabled
- [ ]  Module title and description match the curriculum document
- [ ]  Learning objectives are visible on the LMS module page
- [ ]  Faculty reviewed final upload (watched first 2 mins + last 2 mins)
