# P1.1.1 — Technical SEO Checklist: The Foundation Audit

**Learning Objectives:** Students can run a structured technical SEO audit on any website using a repeatable checklist, and prioritise fixes by impact.

**Outline:**

1. Hook — "Before you write a single word of content, your site needs to be crawlable, indexable, and fast — here's how to check all three in under an hour"
2. Crawlability basics — robots.txt, XML sitemaps, crawl budget (what it is, why it matters for larger sites)
3. Indexability checks — noindex tags, canonical tags, duplicate content traps
4. Site architecture — URL structure, internal linking hierarchy, orphan pages
5. Mobile-first indexing — why Google crawls the mobile version first and what breaks when mobile ? desktop
6. HTTPS, redirects (301 vs 302), and broken link audits
7. **Live demo:** Run through a free tool (e.g. Google Search Console + a crawler) on a sample site, walk through the checklist live
8. The "Technical SEO Checklist" downloadable resource — a one-page audit template students keep and reuse
9. Checkpoint quiz (Sub-Topic Checkpoint template, QW-05)

**Recording notes:** This is the pilot's opening module — extra care on pacing since it sets the tone for the cohort. Follow Faculty Recording & Slide Standards SOP (QW-10). The downloadable checklist should be built as a Notion template or PDF the student can reuse on client sites.

**Practical Exam tie-in:** This sub-module's checklist becomes Task 1 of the P1.1 Module Practical Exam — students run this audit on a real or sample site as part of their final submission.

# P1.1.2 — Core Web Vitals: Performance as a Ranking Factor

**Learning Objectives:** Students can explain the three Core Web Vitals metrics, measure them for any page, and recommend fixes for common failures.

**Outline:**

1. Hook — "Google now grades how your page *feels* to use — not just what it says"
2. The three metrics explained in plain language:
    - **LCP (Largest Contentful Paint)** — how fast the main content loads
    - **INP (Interaction to Next Paint)** — how responsive the page feels when clicked/tapped
    - **CLS (Cumulative Layout Shift)** — how much the page jumps around while loading
3. Why Google cares — user experience signals tie directly to bounce rate and rankings
4. **Live demo:** Run PageSpeed Insights / Search Console Core Web Vitals report on a sample site, interpret the results
5. Common causes of poor scores — unoptimised images, render-blocking scripts, web fonts, ad layout shifts
6. Practical fixes a marketer (not just a developer) can request or implement — image compression, lazy loading, font-display settings
7. Setting up ongoing monitoring — Search Console alerts, periodic checks
8. Checkpoint quiz

**Recording notes:** Keep the technical explanation accessible — this audience is marketers, not developers. Frame everything as "what to ask your developer for" rather than "how to code it yourself," but include enough detail that students can speak credibly to dev teams.

**Practical Exam tie-in:** Task 2 of the Module Practical Exam — students run a Core Web Vitals report on the same site from P1.1.1 and write up 3 prioritised recommendations.

# P1.1.3 — Schema Markup: Speaking Google's Language

**Learning Objectives:** Students can identify which schema types apply to a given page, generate basic schema markup, and validate it.

**Outline:**

1. Hook — "Two identical articles, one with a recipe card / star rating in search results and one without — same content, different click-through rate. The difference is schema."
2. What is structured data / schema markup — a translation layer between your content and Google's understanding of it
3. Common schema types relevant to DM students: Article, Product, LocalBusiness, FAQ, Review/Rating, BreadcrumbList, Organization
4. How rich results work — schema doesn't guarantee rich snippets, but it's a prerequisite
5. **Live demo:** Use a free schema generator tool to build FAQ and Article schema for a sample page
6. Validating markup — Google's Rich Results Test, Schema Markup Validator
7. Common mistakes — marking up content that isn't visible to users, using the wrong schema type, leaving stale data in JSON-LD
8. Connecting back to P1.1.1 — schema audit as part of the technical SEO checklist
9. Checkpoint quiz

**Recording notes:** This module benefits from visual before/after search result screenshots (with schema vs without). Source these from real (non-branded, anonymised where needed) search results to keep it concrete.

**Practical Exam tie-in:** Task 3 (final task) of the Module Practical Exam — students generate and validate schema markup for one page type of their choice, completing the full P1.1 Practical Exam alongside Tasks 1–2.

# P1.1.4 — Keyword Research 2.0: Intent, Clusters & Topical Authority

**Learning Objectives:** Students can move beyond basic keyword volume to build intent-mapped keyword clusters, and explain how topical authority affects ranking in 2026's AI-influenced search environment.

**Outline:**

1. Hook — "Ranking for one keyword is a 2015 strategy. In 2026, Google rewards sites that *own a topic* — here's how to build that."
2. Why search intent beats keyword volume — the four intent types (informational, navigational, commercial, transactional) and how they dictate content format
3. What changed in 2024–2026: AI Overviews (SGE/AIO) and how they shifted which queries send traffic vs which get answered in-SERP
4. **Keyword clustering in practice** — grouping keywords by shared SERP, not just semantic similarity; using free tools (Google Keyword Planner, Search Console, Ahrefs Free, Semrush Free Tier)
5. Building a Topical Authority map — pillar pages, cluster pages, and internal linking logic
6. **Live demo:** Take a real niche (e.g. "email marketing for e-commerce") and build a 10-topic cluster map from scratch
7. Competitive gap analysis — how to find keywords your competitors rank for that you don't
8. Prioritisation matrix — impact (volume × intent match × competition) vs effort
9. Checkpoint quiz

**Recording notes:** This module pairs well with the Technical SEO modules — position it as "now that your site is technically sound, here's how to choose what to rank for." Show the live demo in a shareable Notion/Google Sheet template students can copy. Avoid over-relying on paid tools; every step should be doable on a free-tier budget.

**Practical Exam tie-in:** Homework exercise — students build a 10-keyword cluster map for their pilot site (same site from P1.1.1–3) and submit as part of an extended P1.1 portfolio piece (optional extension for the SEO Mastery Pilot cohort).

# P1.1.5 — Link Building in the AI Era: What Works in 2026

**Learning Objectives:** Students can design an ethical, sustainable link-building strategy that aligns with Google's 2025/2026 spam policies and produces measurable results within a 90-day window.

**Outline:**

1. Hook — "Google has penalised 40%+ of sites that used AI-generated link spam. But real links still move rankings faster than anything else. Here's how to build them the right way."
2. How links work in 2026 — PageRank still matters, but Google's spam classifiers are far stronger; context, placement, and link velocity all matter
3. What is dead: bought links, link farms, PBNs, low-quality directory submissions, mass guest post networks
4. What still works (and is safe):
    - **Digital PR** — newsjacking, original data, expert commentary
    - **Broken link building** — find dead resources, replace with your content
    - **Resource page link building** — identify curated lists in your niche and pitch yours
    - **HARO/Connectively and journalist outreach**
    - **Strategic guest posting** — quality over quantity, real editorial standards only
    - **Partnerships and brand mentions → link conversion**
5. Building a 90-day outreach plan with realistic targets (5–10 quality links/month for a new site)
6. **Live demo:** Run an outreach email sequence using a template that gets replies — show a before/after of a bad pitch vs a good one
7. Measuring link quality — DA/DR as a rough guide, plus manual checks (traffic, relevance, link neighbourhood)
8. Disavow when necessary — what warrants a disavow, how to build the file
9. Checkpoint quiz

**Recording notes:** This is a mindset module as much as a tactics module — students need to understand *why* shortcuts fail, not just that they're told not to use them. Use real examples (anonymised) of sites that recovered from or were damaged by link penalties. Keep the outreach templates concise — students should leave with copy-paste email scripts they can adapt immediately.

**Practical Exam tie-in:** Task 4 of the P1.1 Extended Module Exam (for SEO Mastery Pilot cohort only) — students identify 5 genuine link-building opportunities for their pilot site and write an outreach email for one, ready to send.
