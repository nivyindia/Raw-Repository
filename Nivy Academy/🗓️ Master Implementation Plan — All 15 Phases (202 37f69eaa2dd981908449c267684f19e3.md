# ⚠️ RULES FOR ALL WAVES

1. **No module goes to students before it is in LMS.** Partial uploads do not count as complete.
2. **Every module needs:** Script / Slides → Recording → Edit → Upload → Quiz/Assignment → QA Review. All 6 steps must be done.
3. **No wave starts until 80% of the prior wave is complete.** Waves can overlap by 1 sprint (2 weeks) for planning only.
4. **Status must be updated every Friday** in the tracker before EOD.
5. **Phase 11 (Faculty Standards) applies from Wave 1 day 1** — recording and slide standards must be followed from the start, even before P11 is formally in scope.
