1. **No phase is "done" until all tasks are in the LMS with quizzes built and recordings QA'd.**

3. **Phase 21 checkpoints are built alongside content, not after** — every content writer hands off a checkpoint draft with each module.
4. **Weekly check-ins happen every Friday** using the Master Progress Tracker.
5. **Any phase running more than 2 weeks late** triggers an escalation to Abhishek with a revised plan.
