# NA-AC-07 | VA + AI Integration Module

**Doc ID:** NA-AC-07 · **Dept:** Academic · **Phase:** 1 · **Audience:** All Students · **Language:** English · **Status:** 🟢 Live

**Tags:** VA, virtual assistant, AI, ChatGPT, Claude, Canva, Apollo, automation

---

## 🎯 Module Goal

Every Nivy Academy graduate must be able to work as a **professional Virtual Assistant** using AI tools to deliver 2x the output in half the time. This module runs parallel to the main track in Months 1–2.

---

## 🖥️ Tool-by-Tool Training Plan

### 1. ChatGPT / Claude — AI Writing & Research

| Skill | Task |
| --- | --- |
| Drafting cold emails in 60 seconds | Prompt templates provided |
| Researching a company’s pain points | Research prompt library |
| Writing social media captions | Content prompt pack |
| Creating proposals and decks | Slide outline prompts |
| Summarising long documents | Analysis prompts |

**Assessment:** Write 5 cold emails using AI and submit for review.

### 2. Canva — Professional Design for Non-Designers

| Skill | Task |
| --- | --- |
| Creating branded proposal decks | Template walkthrough |
| Social media graphics (IG, LinkedIn, Facebook) | Design task |
| Professional certificates and documents | Design task |
| Lead magnet PDF creation | Project task |

**Assessment:** Design a 3-slide pitch deck for a mock client.

### 3. [Apollo.io](http://Apollo.io) — Lead Extraction & List Building

| Skill | Task |
| --- | --- |
| Setting up Apollo account and filters | Setup SOP |
| Building targeted lead lists by industry + geography | Hands-on task |
| Finding verified business email addresses | Hands-on task |
| Exporting leads to CRM | Integration task |

**Assessment:** Build a list of 30 qualified leads for a given ICP.

### 4. Bitrix24 / Notion CRM — Pipeline & Task Management

| Skill | Task |
| --- | --- |
| Setting up a lead pipeline | Setup SOP |
| Logging outreach attempts with status tags | Daily log task |
| Creating follow-up reminders | Automation task |
| Submitting weekly CRM reports | Reporting task |

**Assessment:** Maintain a clean CRM log for 2 weeks straight.

### 5. Meta Business Suite — Social Media Management

| Skill | Task |
| --- | --- |
| Scheduling posts across Facebook + Instagram | Hands-on |
| Running a basic ad campaign (traffic objective) | Hands-on |
| Reading ad performance reports | Analysis task |

**Assessment:** Schedule 5 posts for a mock brand page.

### 6. LinkedIn Sales Navigator — B2B Prospecting

| Skill | Task |
| --- | --- |
| Advanced search filters (title, company size, location) | Hands-on |
| Sending InMail vs. connection request strategy | Script task |
| Tracking prospects with Sales Navigator lists | Hands-on |

**Assessment:** Build a 20-person prospect list and initiate 5 connections.

---

## 📌 The "Professional Passport"

Students who complete all 6 tool assessments earn the **Professional Passport** — an internal Nivy badge certifying they can operate at international VA standard. This is mentioned in the Experience Letter.
