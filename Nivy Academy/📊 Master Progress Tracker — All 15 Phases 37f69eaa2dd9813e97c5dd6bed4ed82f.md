# 📖 HOW TO UPDATE THIS TRACKER

**Status Legend:**

- 🔴 Pending — not started
- 🟡 In Progress — work has started but not complete
- ✅ Done — module is in LMS, quiz is built, QA passed
- 🚫 Blocked — cannot proceed until something is resolved

**Who updates what:**

| Section | Who Updates | When |
| --- | --- | --- |
| Master Progress Dashboard (numbers) | Any Phase Owner | Every Friday |
| Currently In Progress table | Task Owner | When task starts |
| Completed Tasks Log | Task Owner | When task is done & in LMS |
| Weekly Check-In Log | Abhishek / Ops Lead | Every Friday EOD |
| Blockers & Dependencies | Anyone facing a blocker | Immediately when blocked |
| Milestone Status | Abhishek | When milestone is hit |

> **Rule:** If a task is marked ✅ Done but the LMS link column is empty, it is NOT considered done. Every completed task must have an LMS link.
