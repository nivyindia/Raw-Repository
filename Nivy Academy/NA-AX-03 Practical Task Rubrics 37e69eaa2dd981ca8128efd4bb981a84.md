## 📌 How to Use This Rubric

For each practical task submitted, mentors score the student across 4 criteria. Each criterion is scored 1–5. Total = /20 converted to a percentage.

---

## 📊 Universal Grading Rubric (All Practical Tasks)

| Criteria | 1 (Poor) | 3 (Acceptable) | 5 (Excellent) |
| --- | --- | --- | --- |
| **Completeness** | Task partially done | Most elements present | 100% complete, nothing missing |
| **Quality** | Generic / copy-paste | Some personalisation | Highly specific, professional quality |
| **Professionalism** | Casual/informal tone | Mostly professional | Perfectly aligned to international standard |
| **CRM Logged** | Not logged | Logged late/incomplete | Logged correctly within 24 hours |

**Score /20 → multiply by 5 = % score**

## 📦 Task-Specific Rubrics

### Task: Cold Email Submission

| Criteria | What to check |
| --- | --- |
| Subject line | Specific, curiosity-driving, not generic |
| Opening line | Personalised to company (not "I hope this email finds you well") |
| Pain point | Correctly identifies a real problem the company has |
| CTA | One clear ask (call, reply, link) |
| Tone | Professional, concise, USA/UK standard |

### Task: Lead List Submission (Apollo)

| Criteria | What to check |
| --- | --- |
| Volume | Minimum 20 leads (30 for full marks) |
| ICP alignment | Leads match the given Ideal Customer Profile |
| Data quality | Verified emails, correct job titles, no duplicates |
| CRM entry | All leads entered in CRM with correct status tags |

### Task: Audit Submission

| Criteria | What to check |
| --- | --- |
| Research depth | 3+ real pain points identified with evidence |
| Structure | Clear sections: findings, impact, recommendations |
| Actionability | Recommendations are specific, not vague |
| Professionalism | Could be shared with the actual company |

### Task: Mock Closing Call (Video)

| Criteria | What to check |
| --- | --- |
| Discovery | Asked at least 3 qualifying questions before pitching |
| Pitch | Tied solution directly to the pain identified |
| Objection handling | Used the scripts correctly, didn’t panic |
| Close | Attempted a clear close ("Shall we get started?" or similar) |
