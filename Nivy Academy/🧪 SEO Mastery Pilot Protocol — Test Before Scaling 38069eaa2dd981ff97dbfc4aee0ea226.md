# 🧪 SEO Mastery Pilot Protocol — Test Before Scaling

> **Status:** Planning | **Pilot Module:** SEO Mastery (Phase 1.1) | **Pilot Cohort Size:** 5–10 students | **Pilot Window:** July 2026 (Wave 1, W1–W4) | **Decision Gate:** September 1, 2026
> 

---

# Why Pilot First

The new checkpoint / scorecard / modular enrolment system (Phases 20–23) is being deployed across 21 modules simultaneously as Wave 1 begins. That is a large surface area for first-time errors — in template design, grading workload, LMS config, and student experience. A single-module pilot with a small cohort catches these problems cheaply before they replicate across every other module.

SEO Mastery is the right pilot module because:

- It is the best-documented module in the existing programme
- Phase 1.1 is the first deliverable in Wave 1 (Jul W1)
- Its content is relatively stable (unlike AI or emerging platforms)
- SEO is the subject area with the highest student enrolment and employer demand

# 📋 Pilot Design

| Element | Detail |
| --- | --- |
| Module | SEO Mastery (P1.1 — 5 depth sub-modules) |
| Cohort | 5–10 current Expert or Professional students |
| Faculty Lead | SEO Faculty (TBC via QW-14) |
| New systems tested | Sub-Topic Checkpoints, Module Practical Exam, Scorecard view, AI-assisted first-pass grading |
| Delivery format | Live sessions (1 per sub-module) + async recordings uploaded to LMS same day |
| Assessment | Sub-topic checkpoints after each session; Practical Exam at end of module |
| Grading | AI first-pass → Faculty review → Scorecard updated |

---

# 📊 What the Pilot Measures

| Metric | Target | How Measured |
| --- | --- | --- |
| Checkpoint completion rate | ≥90% of enrolled students complete all 5 checkpoints | LMS / Notion Scorecard |
| Practical Exam submission rate | ≥85% submit within 72hrs of module end | LMS |
| AI grading accuracy | ≥80% of AI first-pass grades accepted without faculty override | Grading log |
| Faculty time-per-grade | ≤1 hour per student for full module | Faculty self-report |
| Student satisfaction (NPS) | ≥50 | 3-question post-module survey |
| Checkpoint template usability | Faculty can use template without training | Faculty feedback form |

# ✅ Decision Gate Criteria (September 1, 2026)

The SEO Mastery pilot pattern is approved for replication across all Wave 1 modules IF:

- [ ]  Checkpoint completion rate ≥90%
- [ ]  Practical Exam submission rate ≥85%
- [ ]  AI grading accuracy ≥80%
- [ ]  Faculty time-per-grade ≤1 hour per student
- [ ]  Student NPS ≥50
- [ ]  No critical LMS bugs outstanding

If any gate fails: document the issue, fix it in the SEO module, run a 2-week retest before rolling out to remaining modules.
