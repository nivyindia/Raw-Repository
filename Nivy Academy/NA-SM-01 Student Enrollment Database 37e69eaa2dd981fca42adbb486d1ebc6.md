# NA-SM-01 | Student Enrollment Database

*This page serves as the master student registry. Create a Notion database below with the following properties for every enrolled student.*

---

## Database Properties (Columns)

| Property | Type | Description |
| --- | --- | --- |
| Student Name | Title | Full name |
| Email | Text | Primary email |
| WhatsApp | Text | With country code |
| City / Country | Text | Location |
| Batch # | Select | Batch 1, 2, 3... |
| Tier | Select | Trailblazer / Starter / Practitioner / Accelerator / Elite |
| Track | Select | Foundation / Acceleration |
| Enrollment Date | Date | Date formally enrolled |
| Payment Status | Select | Paid / Partial / Pending / Installment |
| Amount Paid | Number | In INR or USD |
| Mentor Assigned | Person | Notion user |
| Status | Select | Active / Completed / Dropped / Suspended |
| Trial Task Score | Number | Out of 100 |
| Notes | Text | Any relevant notes |
