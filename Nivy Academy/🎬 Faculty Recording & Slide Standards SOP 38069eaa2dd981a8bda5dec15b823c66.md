# Purpose

This SOP ensures every module produced for Nivy Academy is:

- Visually consistent across all courses
- Audibly clear and professionally produced
- LMS-uploadable without rework
- Reproducible by any faculty member without briefing

---

# Part A — Slide Standards

## A1. Template & Branding

- Use only the **official Nivy Academy slide template** (link to be added once Design team finalises)
- Fonts: **Headlines** — Montserrat Bold | **Body** — Inter Regular
- Brand colours: Primary Blue (#1A3C6E), Accent Orange (#F4841F), White (#FFFFFF), Light Grey (#F5F5F5)
- Never use yellow text on white backgrounds — fails accessibility contrast
- Logo must appear in the bottom-right corner of every slide

## A2. Slide Structure

Every module must follow this mandatory slide order:

| Slide # | Type | Notes |
| --- | --- | --- |
| 1 | Title Slide | Module name, sub-topic number, faculty name |
| 2 | Learning Objectives | 3–5 bullet points max — what the student will be able to do |
| 3–N | Content Slides | See A3 below |
| N+1 | Key Takeaways | 3 bullet max |
| N+2 | Sub-Topic Checkpoint | Refer to QW-05 template |
| Last | Next Steps | What's coming next + resource links |

## A3. Content Slide Rules

- **Max 40 words per slide.** If you need more, split into two slides.
- One concept per slide. No information dumping.
- Every data claim must cite source + date in slide footer (e.g. "Google Search Central, May 2026")
- Screenshots: minimum 1080p, no browser toolbars visible, crop tightly
- Use arrows, not text boxes, to annotate screenshots
- Avoid clip art. Use icons from [Icons8](https://icons8.com) (free tier is fine)

# Part B — Recording Standards

## B1. Equipment Minimum Requirements

| Item | Minimum | Recommended |
| --- | --- | --- |
| Microphone | USB cardioid mic (Blue Snowball / Samson Go) | Rode NT-USB Mini |
| Camera | 720p webcam | 1080p webcam or DSLR |
| Resolution | 1920×1080 (Full HD) | 1920×1080 |
| Frame rate | 30fps | 30fps or 60fps |
| Lighting | Ring light (front-facing) | 3-point lighting setup |
| Background | Clean wall or virtual background | Branded Nivy background (see Design team) |

## B2. Pre-Recording Checklist

- [ ]  Room is quiet — close windows, switch off AC/fan (or use a noise-suppression plugin like Krisp)
- [ ]  Notifications off on all devices
- [ ]  Script is printed or on a second screen — not on the recording screen
- [ ]  A test 30-second clip has been recorded and reviewed for audio/video quality
- [ ]  Slide deck is on presenter mode (not edit mode)
- [ ]  Timer is visible to you (aim for 8–15 min per sub-topic module)

## B3. Recording Rules

- **Start with a 3-second countdown clapboard** (hands clapping in frame) — makes editing easy
- Begin each recording with: *"Hi, I'm [Name], and in this module we're going to cover [topic]. By the end, you'll be able to [learning objective]."*
- Speak at **120–140 words per minute** — slower than you think is normal
- Pause for 1 full second between major points
- **Do not stop mid-sentence** if you make a mistake — pause, breathe, and repeat from the top of that sentence. The editor will cut it.
- Face the camera directly when making key statements. Glance at slides to point, then return to camera.

## B4. Editing Handoff Rules

- Export raw file as `.mp4` (H.264, AAC audio)
- Name files: `NA-[PhaseCode]-[SubPhase]-[SubtopicNumber]-[FacultyInitials]-RAW.mp4`
    - Example: `NA-P1-1.1-01-SK-RAW.mp4`
- Upload to: **[LMS Production Folder — link TBD]**
- Add a row in the Wave Production Tracker (QW-09 database) with status `🟡 In Progress`
- Editing SLA: **48 hours** from raw upload to edited cut
- QA SLA: **24 hours** from edited cut to LMS-ready approval

# Part C — Editing Standards

## C1. Required Edits

- Remove all silence gaps > 1.5 seconds
- Remove filler words ("um", "uh", "like", "you know") where possible without creating audio jumps
- Add lower-third title card at 0:05 with: Module Name | Sub-Topic | Faculty Name
- Add chapter markers at every new slide section (for LMS scrubbing)
- Add auto-generated captions (review + fix proper nouns and brand names)

## C2. Output Specs

- Format: `.mp4` (H.264 + AAC)
- Resolution: 1920×1080
- Bitrate: 4–6 Mbps video, 192kbps audio stereo
- File naming: `NA-[PhaseCode]-[SubPhase]-[SubtopicNumber]-[FacultyInitials]-FINAL.mp4`
- Maximum file size: 500MB per video. If larger, compress or split.

# Part D — Quality Assurance Checklist

The Ops team QA's every video before it goes to LMS. A video fails QA if any of the below are true:

- [ ]  Audio has background hum, echo, or peaks above -3dB
- [ ]  Resolution is below 1080p
- [ ]  No learning objectives slide
- [ ]  Sub-Topic Checkpoint is missing
- [ ]  Any slide has more than 40 words
- [ ]  File naming is incorrect
- [ ]  Captions are absent or clearly wrong on key terms
- [ ]  Video is longer than 20 minutes (exception: capstone modules with Abhishek approval)
