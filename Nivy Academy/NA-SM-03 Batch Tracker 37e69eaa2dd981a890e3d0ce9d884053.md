## Per-Batch Page Structure

For each batch, create a sub-page with:

### Batch Details

- Batch number and name (e.g. "Batch 1 — July 2026")
- Start date and expected graduation date
- Number of students enrolled
- Assigned mentor(s)
- Track (Foundation / Acceleration / Mixed)
