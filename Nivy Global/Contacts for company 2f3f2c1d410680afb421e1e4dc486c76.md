# **💡 BEST PRACTICES**

1. **Emails:** Role-based, not person-based → avoids disruption when team members change.
2. **Forwarding:** All role-based emails can forward internally to the right person/team.
3. **Phone Numbers:** If budget allows, dedicated numbers look more professional. Otherwise, a single number + extensions works well.
4. **Widgets / CRM Integration:** Connect emails to CRM (HubSpot, Zoho, Salesforce) for tracking leads & tickets.
5. **Website Display:**
    - Use `contact@company.com` as the main public email.
    - Display phone numbers per department if possible, or main + extensions.
